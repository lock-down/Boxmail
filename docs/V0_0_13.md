# 0.0.13：优先工作流与界面统一

日期：2026-10-21。App 和本机后端版本为 **0.0.13**，构建号 **14**，对应本地 Git 标签 `v0.0.13`。本版完成自定义分类，以及 Roadmap 的 E1、A1、A2、B1、B2。具体入口和容量边界见 [优先功能说明](PRIORITY_WORKFLOWS.md)，其他资料见 [文档索引](README.md)。

本文记录标签 `v0.0.13`（提交 `fe4655e`）及对应 Release ZIP 的发布状态。后续界面提交 `2c4f2b8` 沿用 0.0.13 / build 14，改进侧栏、筛选和年月间距，但没有更新此标签或现有 ZIP；其行为与验证见 [当前开发状态](README.md#当前开发状态) 和 [界面检查记录](UI_REVIEW.md)。下方发布行为、测试数字和产物信息保留原记录。

## 功能变化

| 功能 | 发布行为 |
| --- | --- |
| 自定义分类 | 所有账户共用分类名称和说明，可新增、改名、删除；手动标记与 AI 任务使用同一目录，建议仍需确认，可撤销 |
| A1 会话阅读 | 同账户依据 Message-ID、In-Reply-To 和 References 建立往来时间线，逐封展开、回复、移动；引用内容可折叠 |
| A2 联系人补全 | 从当前账户本机历史邮件和草稿推荐 To / Cc / Bcc，按使用频率与时间排序，支持键盘选择、片段替换和跨字段去重 |
| B1 全文搜索 | 中文双字符 n-gram 索引覆盖主题、正文、附件名称及已提取内容、AI 结果，增量更新并可手动重建 |
| B2 条件搜索 | 组合关键词、往来对象、日期、状态、附件、账户和文件夹，显示来源、命中片段与具体查询错误 |
| E1 完整备份恢复 | ZIP 保存一致性数据库快照、登记的附件及 SHA-256 清单；校验后确认恢复，恢复前保留当前完整数据 |

搜索状态包含全部状态、未读、已读、星标、已发送、草稿箱、已归档和已删除；文件夹状态与文件夹菜单同步。明确选择草稿箱时检索当前本机未发送草稿，结果可继续编辑原草稿，已发送记录排除。

## 界面与日历

搜索表单按条件分组；分类管理采用目录与编辑分栏；会话、联系人建议、备份及索引操作沿用系统字体、蓝灰色和 SF Symbols。下拉选择共用无描边原生菜单，操作按钮采用纯图标文字，补齐“写邮件”“更改位置”的样式和“保存备份”的图标。设置数字调节、输入焦点及滚动区保持轻量反馈。

日期通过日历选择，不要求手输。日期面板宽 360 pt，年月菜单居中且无填充底，左右翻月按钮对称；星期与日期网格对齐，移除原来的额外内边距和两侧大块留白。可选择年份、月份、今天或清除，返回条件表单时保留其他输入。日期按本机时区计算，起始日包含、截止日不包含。

## 数据与兼容性

继续使用 SQLite `user_version=2`，现有邮件、附件、草稿、自定义提示词、模型缓存和待同步操作保留。分类目录持久保存；旧默认分类提示词精确升级，自定义提示词保持原值。全文索引为可重建派生数据，不替代历史同步；未缓存邮件仍不在本机搜索与会话范围内。

完整备份不包含钥匙串凭证，ZIP 未加密；支持压缩后 512 MB、解压后 2 GB 以内，更多限制见 [备份说明](PRIORITY_WORKFLOWS.md)。恢复不会自动重发中断邮件，运行中的任务转为可检查或继续的状态。会话 AI、云通讯录、服务器草稿同步和后续 Roadmap 候选不包含在本版。

## 验收

`./script/test.sh` 通过 **133 项后端测试、45 项 Swift 测试**，后端无跳过。覆盖备份损坏与篡改、无效记录及引用、恢复失败保护、维护互斥、自定义分类实际请求、引用链与跨账户隔离、联系人补全、中文全文与增量更新、条件分页、本机草稿、跨时区日期及月历排列。

原生流程使用独立 App、数据、钥匙串服务和两个演示账户，包含 11 封合成邮件、本机草稿及附件；AI 仅连接本机模拟服务。确认分类新增、应用和撤销，会话逐封回复身份，联系人键盘及去重，中文和跨账户搜索，草稿继续编辑，日历翻月与菜单、日期回填及输入保留，备份保存、检查确认、恢复前备份和索引重建。界面记录见 [UI 检查](UI_REVIEW.md)。

发布检查核对开发及 Release App 的版本、构建号、签名、资源与内置后端，解压 ZIP 后核对逐文件内容和 SHA-256，并在独立空数据目录验证首次启动不含演示账号。发布日志与校验结果位于 `artifacts/release-v0013/`，功能和界面证据位于 `artifacts/priority-ui/`；本机证据、个人数据和构建产物不提交 Git。
