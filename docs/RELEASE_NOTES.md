# Boxmail 0.1.11

2026-11-24 · build 50 · 本地发布

## 界面与操作

- **收件箱与工作区。** 邮件列表、阅读区、附件与设置采用统一的 coss UI 样式，窄窗口可以从两侧展开邮箱导航和邮件助手。
- **菜单与表格。** 下拉和右键菜单统一显示当前选项，支持方向键、回车和 Esc。邮件列表、压缩包目录和规则记录统一了表格行样式。
- **写信。** 格式栏集中提供字号、预设色、自定颜色、列表和链接，底栏集中显示草稿状态、附件、定时发送和发送。
- **日期和时间。** 搜索条件分别选择起止日期。定时发送和改期可直接输入小时与分钟，跟进可以从列表选整点。
- **界面图标。** 侧栏、工具栏、状态和写信控件统一使用 Remix Icon。

## 安装

本地安装包适用于 Apple Silicon，内置 Node.js 26.13.1 LTS 和使用指南。App 声明最低 macOS 14，本包在 macOS 27.2.1 验证，采用临时签名。

将 ZIP 和同名 `.sha256` 文件放在同一目录，运行 `shasum -a 256 -c Boxmail-v0.1.11-macos-arm64-clean.zip.sha256` 校验。升级前先完全退出 Boxmail，再替换 App。
