# Boxmail 0.1.12

2026-11-26 · build 51 · 本地发布

此页对应 Boxmail 0.1.12 本地安装包。

## 功能与操作

- **标签与整理。** 同一封邮件可加多个标签，收件箱支持按标签筛选。可从清单选择已缓存邮件整理，或按邮箱开启新信自动整理。旧版含 AI 动作的自动规则会暂停，可在设置中查看。
- **清单。** 同一封邮件的摘要、待办和手工事项显示在一起，可逐项勾选、编辑提醒或打开原邮件。
- **翻译。** 阅读区可直接翻译邮件，按邮箱记忆自动翻译和目标语言，同一封邮件按语言保留译文。
- **写信。** 「帮我写」可改写选区或正文，也可生成回复候选，采用后可撤销。点击正文空白处可回到正文末尾，签名文字可直接编辑。切换草稿发件账户后可正常保存并关闭。
- **草稿箱。** 待发送邮件可直接编辑、改期或取消。编辑时暂停投递，保存关闭后恢复尚未到期的原计划。发出的邮件在「已发送」查看。
- **历史结果。** 旧分析、会话结论、问答和回复预览可从来源邮件查看，附件分析可从附件预览查看。邮箱规则移到设置，运行记录和用量可从活动记录查看。
- **界面。** 功能图标换用 Appica Icons，常规图标从 14 pt 增至 18 pt。卡片、浮层和控件采用递进式连续圆角，展开按钮去除悬停和按下时的背景。

## 安装

本地安装包适用于 Apple Silicon，内置 Node.js 26.13.1 LTS 和使用指南。App 声明最低 macOS 14，构建环境为 macOS 27.2.1，采用临时签名。

将 ZIP 和同名 `.sha256` 文件放在同一目录，运行 `shasum -a 256 -c Boxmail-v0.1.12-macos-arm64-clean.zip.sha256` 校验。升级前先完全退出 Boxmail，再替换 App。
