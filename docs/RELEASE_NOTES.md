# Boxmail 0.1.10

2026-11-19 · build 49

## 新功能

- **邮件助手。** 从右侧直接问当前文件夹里的邮件或草稿，也可以针对一封邮件、一次会话或选中的附件提问。助手在本机找出相关资料，再按模型容量选取片段。回答会标出查阅范围，点击来源可打开原邮件或附件。
- **邮件工作台。** 摘要和跟进放在同一个入口。点待办旁的「收录跟进」即可设提醒或延后到某个整点，等待对方的提醒会在收到回复后解除。
- **规则与用量。** 先预览条件匹配了哪些邮件，再运行分类、归档或 AI 处理。可以启用新邮件自动规则，失败项可重试，邮件状态改动可从记录撤销。AI 用量可按实际调用查看。
- **写信与发送。** 可为不同账户设置签名，保存常用写作风格，或只重写选中的文字。确认普通发送后有 10 秒可以撤回到草稿，定时邮件可在「发送管理」改期或取消。
- **收件箱与附件。** 可合看所有账户的收件箱，保存常用查询，给分类自选颜色。从文件列表打开附件后，可以前后浏览同一封邮件的其他文件。

## 阅读和修复

- 摘要的关键事实归为四组，已有摘要打开时也会合并同类信息。中文粗体、Markdown 文件和 ZIP 内的 Markdown 可直接按排版阅读。
- 修复邮件列表滚动条闪烁、返回搜索时残留旧结果、分类计数串页、规则暂停后无法继续处理，以及旧发送计划干扰新计划的问题。

## 安装

本地安装包适用于 Apple Silicon，内置 Node.js 26.13.1 LTS 和使用指南。App 声明最低 macOS 14，本包在 macOS 27.2.1 验证。当前使用临时签名，Developer ID 签名和公证尚未办理。

把 ZIP 和同名 `.sha256` 文件放在同一目录，运行 `shasum -a 256 -c Boxmail-v0.1.10-macos-arm64-clean.zip.sha256` 核对下载文件。
