# Boxmail 1.0.0

2026-11-28 · 构建号 52

Boxmail 是面向 Mac 的邮件客户端。1.0.0 提供多账户收发、中文搜索、按来源邮件整理的待办清单，以及使用自选模型服务的翻译和写作。

## 功能

- 统一收件箱支持按发件人聚合、多标签、批量操作与撤销。搜索覆盖邮件正文、附件名称和本机已提取的附件内容，常用查询可保存到侧栏。
- 待办清单将摘要、事项和手工跟进放在来源邮件下。可选信批量整理、试用标签，或通过「整理助手」起草规则。规则与整理进度可在设置和活动记录中查看。
- 阅读区可翻译并保留原排版。「帮我写」提供改写与回复候选。草稿在正常退出前保存，待发送邮件可继续编辑、改期或取消。
- 设置支持自带 API 密钥、多账户签名、配置迁移和完整备份恢复。使用已保存的数据目录升级时，会继续读取原有邮件和草稿。

## 安装

安装包适用于 Apple Silicon，内置 Node.js 26.13.1 LTS 和生产依赖。应用声明最低 macOS 14，发布包在 Apple Silicon 的 macOS 27.2.1 上验证。安装包采用临时签名，Developer ID 签名和公证尚不可用。

将 ZIP 和同名 `.sha256` 放在同一目录，校验后解压。覆盖安装前，用 Command-Q 完全退出 Boxmail，再将 `Boxmail.app` 放入「应用程序」。新安装从空账户开始。

```bash
shasum -a 256 -c Boxmail-v1.0.0-macos-arm64-clean.zip.sha256
```

详细操作见包内的 `使用说明.md`。[源码更新日志](https://github.com/lock-down/Boxmail/blob/v1.0.0/CHANGELOG.md)
