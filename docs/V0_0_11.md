## 设置下拉菜单

邮箱账号编辑中的 SSL/TLS 与 STARTTLS 两个互斥勾选项改为单一下拉选择。IMAP 与 SMTP 分别显示所选方式，使用原生菜单 Picker 列出两项并标记当前值。仍映射到原有 `imapTLS` / `smtpTLS` 布尔值，没有增加明文连接选项，也不需要迁移已有账号。

选择其他加密方式时，端口仍在使用原默认值才跟随切换：IMAP 为 993 / 143，SMTP 为 465 / 587；用户自定义端口保留。端口与菜单增加对应协议的辅助功能名称，菜单可用键盘选择。

AI 模型与思考等级按参考图合并为紧凑入口，收起时显示当前模型及等级；点击后弹出“模型”“思考等级”两行，各行左侧为标签、右侧为当前值与子菜单箭头。子菜单使用系统选中标记及键盘选择。思考等级显示 Low / High / Max，继续保存为 `low` / `high` / `max`；保留原有默认 High、应用/确定保存、取消放弃和重启恢复行为。此调整不触发模型调用。

模型子菜单列出当前值及刷新得到的模型，长名称中间省略并保留完整提示和配置值；“自定义模型”打开单独的编辑窗口，空白名称不可使用，提交时移除首尾空白。尚未刷新列表时仍可使用当前模型或自定义模型。

## 设置表单布局

账号与 AI 参数共用横向表单：标签左对齐、宽度 88 pt，列间距 12 pt，输入控件高度 32 pt。API 地址、API Key、模型设置与请求超时从同一起点排列。服务器地址占据剩余宽度，端口固定 72 pt，加密下拉框固定 132 pt，并增加共用列标题；长选项不会挤动地址和端口。端口数字不再显示千位分隔符。

模型组合入口收窄为 252 pt，主菜单最小宽度 228 pt，当前值使用 184 pt 右侧制表位；子菜单按内容确定宽度，Low / High / Max 不再占用模型菜单的宽度。长模型名按文字实际宽度省略，仅省略时显示完整提示，自定义编辑窗口为 340 pt。请求超时独立一行，输入后明确显示“秒”，说明文字与输入区域左侧对齐。测试连接和刷新列表共用 112 × 32 pt 的纯图标文字按钮，移除边框与选中背景；悬停改变文字颜色，键盘焦点增加下划线。公共表单控件集中在 `SettingsFormControls.swift`，组合入口在 `SettingsAISelectionView.swift`；`SettingsSelectionMenu.swift` 使用窄 AppKit 桥接，原生菜单负责键盘焦点及子菜单，两行内容保留左侧标签与右侧当前值。

## 模型列表缓存

点击“刷新列表”成功后，模型列表立即保存到本机 SQLite，关闭设置或重启 App 后自动读取，无需再次访问模型服务。缓存以规范化的 API 地址区分，地址末尾的斜杠不产生重复缓存；切换服务时读取各自列表，不混用选项。缓存随本机数据目录迁移和备份，不包含 API Key。

下一次成功刷新完整替换该服务的旧列表，合法的空列表会清空缓存；网络错误、服务错误或响应格式异常时保留旧列表。刷新不改变已选模型和思考等级，当前自定义模型仍可选择。列表缓存独立于配置的“应用 / 取消”，刷新成功后立即保留；配置字段仍按原有保存规则处理。

## Roadmap 优先范围

用户确认按建议优先保留五项：A1 完整会话阅读、A2 联系人补全、B1 全文索引、B2 条件搜索、E1 完整备份恢复。E1 在新数据结构升级前先补齐恢复保障，随后推进会话与联系人，再推进索引和条件搜索；按独立功能分版本验收。

其余 20 项保留为后续候选，未删除且未自动纳入近期版本。会话 AI A5 在会话归并 A1 之后，自动分类与预拟回复 D2 在规则预览 D1 之后；Gmail、Outlook 专用接入及 OAuth 继续排除。五项优先功能尚未实现，本轮只更新计划及设置控件。

完整范围与验收条件见 [Roadmap](GITHUB_RESEARCH_AND_ROADMAP.md)。

## 验证

`./script/test.sh` 通过 99 项后端测试和 36 项 Swift 测试；日志在 `artifacts/tests-v0011.log`。新增四项集成测试覆盖模型列表持久化、后端重启、规范化和地址隔离、成功替换与空列表、失败保留，以及缓存不包含密钥。
