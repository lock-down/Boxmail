# Boxmail 文档索引

当前发布版本为 **0.0.15（build 16）**，对应本地 Git 标签 `v0.0.15`，新增高级设置中的配置导出与导入，继承写信与附件预览修复。发布包与验证见 [0.0.15 发布说明](V0_0_15.md)，较早阶段保留当时的行为、产物及验收结果。

[配置导出与导入](CONFIGURATION_TRANSFER.md) 使用未加密 JSON 迁移邮箱参数与授权码、AI 配置与 API Key、签名及其他偏好。导出按需读取钥匙串，导入预览后按邮箱合并，保留已有邮件、附件和草稿；功能已同步纳入源码、本地 App 与 Release ZIP。

自定义分类、会话阅读、联系人补全、全文与条件搜索、完整备份恢复已随 0.0.13 归档。搜索包含完整状态、日历选日期和本机草稿检索。通用操作保持无描边图标文字样式，写邮件入口与选中筛选使用浅蓝底；入口、限制和验收见 [优先功能说明](PRIORITY_WORKFLOWS.md)。

写信修复同步纳入源码、日常开发 App 和 Release ZIP：联系人浮层仅显示关键词匹配项，无首字头像，保持顶部与输入行布局稳定；三个收件字段恢复聚焦下划线，签名置底，Word 单栏居中。正文可复制粘贴文件和图片添加附件，附件栏保留“添加附件”入口。行为与验证见 [界面检查记录](UI_REVIEW.md#2026-10-22写信与附件预览修复)。
