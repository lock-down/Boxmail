[同类项目调研与 Roadmap](GITHUB_RESEARCH_AND_ROADMAP.md) 保留 2026-10-19 的调研快照，并记录当前确认范围：优先 E1 完整备份恢复，再推进 A1 完整会话阅读、A2 联系人补全，随后推进 B1 全文索引、B2 条件搜索。五项均待开发，其余 20 项为候选。Gmail、Outlook 专用接入及 OAuth 暂不安排。
