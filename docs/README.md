# Boxmail 文档索引

最近发布版本为 **0.0.13（build 14）**，对应 Git 标签 `v0.0.13`。本版完成自定义分类及五项 Roadmap 优先功能，并优化相关界面、无边框按钮和紧凑日历。阶段记录保留各自的验证结果，当前行为以本页链接的使用说明和 [0.0.13 发布说明](V0_0_13.md) 为准。

自定义分类、会话阅读、联系人补全、全文与条件搜索、完整备份恢复已随本版归档。搜索包含完整状态、日历选日期和本机草稿检索，操作按钮统一为纯图标文字样式；入口、限制和验收见 [优先功能说明](PRIORITY_WORKFLOWS.md)。

## 开发路线

[同类项目调研与 Roadmap](GITHUB_RESEARCH_AND_ROADMAP.md) 保留 2026-10-19 的调研快照，并记录当前确认范围：优先 E1 完整备份恢复，再推进 A1 完整会话阅读、A2 联系人补全，随后推进 B1 全文索引、B2 条件搜索。五项已完成本轮开发与验证，其余 20 项继续保留为候选。Gmail、Outlook 专用接入及 OAuth 暂不安排。
