# 开发路线

Boxmail 围绕通用 IMAP／SMTP、原生 macOS 操作和自带 API 密钥的 AI 功能开发。当前行为见 [使用指南](USER_GUIDE.md)，1.0.0 的交付范围见 [更新日志](../CHANGELOG.md)。

## 1.0.0 已实现

| 范围 | 已实现 |
| --- | --- |
| 收件箱与搜索 | 多账户统一视图、同发件人聚合、已保存视图、多标签筛选、中文全文及组合条件搜索。附件搜索可定位到来源邮件。 |
| 阅读与历史 | 阅读区提供按邮箱配置的翻译。旧整封分析、会话结论、回复预览、问答和已保存的附件分析沿各自来源读取。 |
| 清单与规则 | 摘要、待办和手工事项按来源合并。可选信整理或按邮箱授权处理新信。规则在设置中管理，运行结果和用量从活动记录查看。 |
| 写信与投递 | 写作浮层支持选区改写、正文改写和回复候选。原生编辑器处理签名、富文本和撤销。服务器草稿保留编辑冲突，待发送邮件可在草稿箱继续编辑、改期和取消。 |
| 数据与同步 | 支持本机数据迁移、备份校验与恢复、按账户同步隔离和可选的 IMAP IDLE。 |

升级沿用旧摘要、译文、草稿、分析和问答。旧单分类继续用于已有规则和保存视图。依据源码核对兼容行为见 [AI 上下文与数据兼容](MAIL_AI_CONTEXT.md) 和 [后端接口](../Backend/README.md)。

## 后续验证与候选

以下事项仍待评估或专项验证，暂无发布时间。

| 方向 | 工作范围 |
| --- | --- |
| 同步与资源实测 | 补充大邮箱、长期 IMAP IDLE、复杂 PDF／PPT 与多账户并发。分别记录客户端、WebKit、后端及解析子进程，再区分合成负载与真实网络。 |
| 正式分发与更新 | 验证 Developer ID 签名、公证、更新渠道，以及声明的最低系统和目标芯片。 |
| 本机缓存加密 | 共同评估数据库、附件、密钥管理、迁移及备份恢复。 |
| macOS 邮件入口 | 评估本地 EML、mailto 和默认邮件应用，复用现有正文渲染、地址解析和发信确认。 |
| 键盘操作 | 评估自定义快捷键，保留邮件列表及文本编辑的作用域。 |
| 周期 AI 任务 | 评估本机运行条件、按账户授权、去重、用量及执行记录。 |
| 本地 MCP 接口 | 先评估只读查询的账户边界和可审计性，再考虑需要现有确认流程的操作。 |

Gmail／Outlook 专用接入、OAuth、移动端、云端常驻运行和团队协作暂无排期。每项新行为按 [开发说明](DEVELOPMENT.md) 验证。合成回归、隔离 App 操作和真实服务验证各自记录适用范围。
