# 开发路线

目标是让 Boxmail 成为日常主力邮箱，继续完善通用 IMAP/SMTP。当前计划暂时排除 Gmail、Outlook 专用接入及 OAuth；以下候选不自动进入近期版本。

## 已完成的优先功能

| 编号 | 功能 | 已实现范围 |
| --- | --- | --- |
| A1 | 完整会话阅读 | 同账户按引用链归并、当前邮件置顶及倒序时间线、引用折叠、逐封操作保留原身份；预览排除签名并保留引用，本机已发送回复立即关联 |
| A2 | 联系人补全 | 本机历史和草稿、姓名与地址、键盘选择、光标片段替换及跨字段去重；按账户查询必要字段 |
| B1 | 全文索引 | 中文双字符 n-gram、正文与附件及 AI 结果、增量更新与重建；失败回滚，跳过无变化记录 |
| B2 | 条件搜索 | 关键词、往来对象、日期、状态、附件、账户、文件夹及分页 |
| E1 | 完整备份恢复 | 数据库和附件快照、逐项校验、恢复前备份及失败回滚 |

五项随 0.0.13 发布，同时增加自定义分类。本机草稿与日历搜索、写信和附件修复、配置与密钥迁移也已完成。0.0.21 修复数据一致性问题，并优化账户查询、同步和索引更新；0.0.24 补齐升级后的目录锁恢复与退出清理，进一步降低同步和 AI 资源开销；0.0.25 补齐草稿箱和关联回复卡片的签名过滤预览。查询基准及运行时压力测试均已加入开发脚本。当前使用范围见 [使用指南](USER_GUIDE.md)，版本变化及验收见 [CHANGELOG](../CHANGELOG.md)。

## 后续实现与验收约定

- 会话 AI 在 A1 后推进，输出应能定位依据邮件，新回信提示旧结果需刷新，不覆盖用户编辑。
- 规则先提供预览与处理记录，再增加自动执行；复用任务持久化、暂停、确认和撤销，按消息、规则及模型配置去重。邮件内容作为数据，不得改变任务权限。
- 跟进状态由用户确认并可修改；收到对方回复取消提醒，重启补处理到期事项。
- 统一视图及搜索保持原账户和邮件身份；中文检索继续覆盖两字词、句中词、文件名及中英混排，未缓存历史明确提示。
- 同步优化覆盖千封以上回填、断网及重启、UIDVALIDITY、离线更改和账户失败隔离，再测更大数据量；退出、睡眠或离线时不承诺实时执行。
- 资源优化继续补充真实大邮箱、复杂 PDF / PPT 和长期运行测量；分别统计客户端、WebKit 与后端，区分合成负载结果与真实网络耗时。
- 撤销发送仅限 SMTP 提交前；定时任务区分等待和已执行。正式分发、加密及结构迁移均需各自的恢复与兼容验证。
