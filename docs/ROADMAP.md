# 开发路线

目标是让 Boxmail 成为日常主力邮箱，继续完善通用 IMAP/SMTP。当前发布为 0.1.9（build 48），下文记录已发布功能与后续候选，范围截至 2026-11-13。当前计划暂时排除 Gmail、Outlook 专用接入及 OAuth；以下候选不自动进入近期版本。

## 已完成的优先功能

| 编号 | 功能 | 已实现范围 |
| --- | --- | --- |
| A1 | 完整会话阅读 | 同账户按引用链归并、当前邮件置顶及倒序时间线、引用折叠、逐封操作保留原身份；预览排除签名并保留引用，本机已发送回复立即关联 |
| A2 | 联系人补全 | 本机历史和草稿、姓名与地址、键盘选择、光标片段替换及跨字段去重；空地址框的鼠标和 Tab 切换稳定，按账户查询必要字段 |
| A3 | 写信编辑增强 | 原生富文本正文、粗体、项目符号与编号列表、链接；编辑撤销、中文输入法、HTML 与纯文本发送、独立转发原文快照；字号、预设及自定颜色，列表标记随正文格式调整 |
| A4 | 服务器草稿同步 | 随邮箱或单独同步 IMAP 草稿、附件与密送；持久化 APPEND 意图、版本校验、双方编辑冲突副本、远端删除保护及 UIDVALIDITY 隔离 |
| A5 | 会话 AI | 根据同账户缓存引用链总结进展、未决事项与下一步；逐项依据跳转、上下文回复预览、最新邮件关联、过期结果拦截及已编辑草稿保护 |
| B1 | 全文索引 | 中文双字符 n-gram、正文与附件及 AI 结果、增量更新与重建；后台逐封更新，单封失败隔离，大草稿有界索引 |
| B2 | 条件搜索 | 关键词、往来对象、日期、状态、附件、账户、文件夹及分页 |
| E1 | 完整备份恢复 | 数据库和附件快照、逐项校验、恢复前备份、跨卷复制及失败回滚；恢复后列出需重填的凭证 |
| E5 | 本机凭证文件 | 邮箱授权码与 API Key 使用 `.env`，后台读取无需钥匙串；配置与备份仅在端点、协议及身份一致时沿用本机绑定 |

A3、A4、A5 随 0.1.6 发布，0.1.7 完善富文本与地址框焦点，0.1.8 增加 ZIP 资料包、共用分页列表及原生窗口缩放，并修复草稿同步、备份和启动开销。各版细节及验证范围保留在 [变更记录](../CHANGELOG.md)，使用范围见 [使用指南](USER_GUIDE.md)。

### 0.1.9 已发布改进

- 整封理解与 AI 回复共用正文、全部可读附件和 ZIP 子项，原始资料联合提交并展示覆盖范围；独立附件分析保留。
- 收件信息共用折叠组件，长名单展开为 240 pt；名单与正文按当前鼠标位置独立滚动，覆盖 HTML 和纯文本引用、转发及草稿搜索。
- 分页状态、设置动作、凭证暂存、预览流水线及双端规则完成合并，已评估保留项见 [代码审查](CODE_REVIEW.md)。
- 文字按钮、筛选、分段选择与回复预设统一组件，集中维护尺寸、圆角、对称留白、状态与键盘焦点；原生下拉按字体高度居中。
- 附件排序表头与数据列对齐，滚动视口收缩时内容保持靠左；摘要三栏标题与关键信息反馈保持对齐，智能整理空态位于列表内部。
- 窄表格合并来源和理解状态，主要面板按当前窗口收缩并保持底栏可见；会话操作换行，长依据名称保留日期及完整提示。

这些变化保持旧邮件、草稿与 AI 结果兼容；源码验证见[本版变更](../CHANGELOG.md#019--2026-11-13)，尺寸与复用规则见 [UI 规范](DESIGN.md)。

## 后续实现与验收约定

- 界面变更复用现有控件和列表表面，同时检查按钮内部、列起点和整窗布局；覆盖宽窄窗口、视口收缩、长内容及嵌套面板，避免只验证控件宽度。
- 会话 AI 保持依据邮件定位、新回信后的过期提示及用户编辑保护；后续扩展须保留这些约束。
- 规则先提供预览与处理记录，再增加自动执行；复用任务持久化、暂停、确认和撤销，按消息、规则及模型配置去重。邮件内容作为数据，不得改变任务权限。
- 跟进状态由用户确认并可修改；收到对方回复取消提醒，重启补处理到期事项。
- 统一视图及搜索保持原账户和邮件身份；中文检索继续覆盖两字词、句中词、文件名及中英混排，未缓存历史明确提示。
- 同步优化覆盖千封以上回填、断网及重启、UIDVALIDITY、离线更改和账户失败隔离，再测更大数据量；退出、睡眠或离线时不承诺实时执行。
- 资源优化继续补充真实大邮箱、复杂 PDF / PPT 和长期运行测量；分别统计客户端、WebKit 与后端，区分合成负载结果与真实网络耗时。
- 撤销发送仅限 SMTP 提交前；定时任务区分等待和已执行。正式分发、加密及结构迁移均需各自的恢复与兼容验证。
