# Boxmail 全新安装测试包

最近发布的测试包为 **0.0.13（build 14）**，对应本地 Git 标签 `v0.0.13`。测试文件为 `Boxmail-v0.0.13-macos-arm64-clean.zip`，同目录提供 `.zip.sha256` 校验文件。完整验收记录见 [0.0.13 发布说明](V0_0_13.md)，源码文档入口见 [文档索引](README.md)。

后续开发提交 `2c4f2b8` 保持相同版本号和构建号，但其侧栏、筛选和年月间距调整未包含在现有 ZIP 中。本页安装步骤及下方 0.0.13 发布检查针对已有标签测试包；新版界面需使用包含该提交的源码构建，并核对实际源码标识，详见 [当前开发状态](README.md#当前开发状态)。

此包用于 Apple 芯片 Mac（M 系列），要求 macOS 14.0 或更高版本。已内置本机服务、Node.js 和运行依赖，无需安装开发工具或连接这台开发电脑。PPT 页面组件也已内置，预览与逐页理解无需另外安装 Office 或 LibreOffice。

## 安装与首次配置

1. 将 ZIP 复制到测试 Mac，双击解压。
2. 将 `Boxmail.app` 拖到“应用程序”，从“应用程序”打开。
3. 打开“设置 > 账号”，添加邮箱服务器信息和授权码，分别在 IMAP / SMTP 下拉菜单选择 SSL/TLS 或 STARTTLS，测试连接后保存并同步。
4. 打开“设置 > AI 助手”，填写 API 地址及 API Key，刷新模型列表，在模型设置中选择模型与思考等级，测试连接后保存；也可输入自定义模型。

核对下载内容时，将 ZIP 与 `.zip.sha256` 放在同一目录，在该目录执行 `shasum -a 256 -c Boxmail-v0.0.13-macos-arm64-clean.zip.sha256`，结果应为 `OK`。

本包未包含个人邮箱账号、授权码、API Key、邮件、附件、草稿或自定义设置，并关闭演示数据。没有使用过 Boxmail 的 macOS 用户首次启动时账号与邮件列表为空，其他选项及提示词采用应用默认值。

此包不会删除测试电脑上已经存在的 Boxmail 数据。若该电脑曾经使用过 Boxmail，应用会继续读取该用户已有的数据和钥匙串；需要完全隔离时，请在新的 macOS 用户中测试。打包过程不会清空开发电脑的数据。

## 系统首次打开提示

此版本使用本机临时签名，尚未使用 Apple Developer ID 签名或完成公证。下载或传输后，macOS 可能阻止首次打开。

确认文件来自本次测试包后，先尝试打开一次，再进入“系统设置 > 隐私与安全性”，在安全性区域选择“仍要打开”，按系统提示确认。不同 macOS 版本的文字可能略有差异；无需关闭系统安全检查。操作说明见 [Apple：在 Mac 上安全打开 App](https://support.apple.com/zh-cn/102445)。

首次保存或读取邮箱授权码、AI 密钥时，系统可能请求钥匙串授权。输入测试 Mac 当前用户的登录密码，根据需要选择“始终允许”。

## 建议测试

检查邮箱连接与同步、HTML 正文和图片、大批量收件人内部滚动、多附件总结、附件理解与原文切换、AI 翻译与回复、智能整理，以及退出后重新打开的数据保留。发送邮件前请确认测试收件人；云端 AI 请求会将任务所需内容提交到你配置的服务商。

补充检查 PDF 红、表格绿、Word 蓝、PPT 金的图标，以及附件中心的 PPT 筛选。使用含文字、图表和图片的 PPT / PPTX 验证原文件预览、单附件理解和邮件批量理解；每次最多 20 页，超出会提示拆分。理解采用静态页面，复杂动画、视频和特殊字体可先在原应用导出 PDF。

0.0.10 增加数据位置检查：在“设置 > 高级”选择一个空文件夹，先取消设置确认位置未改，再选择并应用、退出和重新打开。核对邮件、附件预览、草稿、已有 AI 结果和待同步状态均保留，当前路径指向新目录，原目录仍存在。选择有内容的目录或当前目录的子目录应显示具体说明。使用外置盘时，退出 App、断开磁盘再打开，应显示目录不可用及重试入口；接回后可恢复，不应建立空邮箱。

0.0.11 检查账号编辑中的两个加密方式下拉菜单：切换 SSL/TLS / STARTTLS 后，默认 IMAP 端口在 993 / 143 间、SMTP 端口在 465 / 587 间联动，自定义端口保留。AI 参数标签左对齐，测试连接与刷新列表均无边框及选中背景。模型设置入口同时显示模型和等级，展开后有“模型”“思考等级”两行及各自紧凑子菜单，等级包含 Low / High / Max 并标记当前选项；模型列表可刷新，也可手动输入自定义名称。保存并重新打开后仍保持选择，取消设置时放弃未应用的配置修改。

模型列表刷新成功后，关闭设置及退出重启均应保留可选项；再次成功刷新应完整替换原列表，失败时保留已有列表。切换 API 地址后应显示对应服务的缓存，切回后恢复之前的列表；列表刷新结果即时缓存，不受配置“取消”影响。

0.0.12 使用专门的测试邮件检查：

1. 分别从收件箱和已发送删除邮件，再恢复，目标应各自回到收件箱和已发送；重启或同步后结果一致。详情按钮和右键菜单应显示实际目标。
2. 分别从收件箱和已发送归档，再点击“取消归档”，应回到各自来源；归档邮件删除后恢复，仍可继续取消归档。
3. 已发送侧栏显示本机数量，移入、恢复和取消归档后即时变化，空文件夹显示 0。列表底部为当前账户、当前文件夹的本机数；在“设置 > 高级 > 本机数据”中，应能找到对应明细并核对全部账户合计。搜索和筛选不改变缓存总数，服务器数单独标明为上次同步结果。
4. 选中邮件后滚动列表及正文，检查细滑块没有轨道和描边；设置、写信及附件预览的横向和纵向滚动同样检查。
5. 已删除标题右侧显示“清空”。先取消确认，邮件应保留；仅在确认当前测试账户的全部已删除邮件都可永久丢弃后执行清空，范围包含未下载和未显示的服务器邮件。操作不可撤销。

旧版没有原文件夹记录的邮件，会先按仍保留的服务器路径，再按发件地址推断；已丢失的原始来源无法准确还原。升级沿用现有数据库、附件和钥匙串，本版不改变数据库结构版本。

0.0.13 补充检查本次优先功能：

1. 在“智能整理 > 管理分类”新增名称和说明，确认手动标记及 AI 建议使用相同目录；分类先预览、确认后应用，撤销能恢复原标签。改名后相关邮件同步更新，删除分类时邮件保留。
2. 打开具有引用关系的往来邮件，检查同账户时间线、引用折叠和逐封回复，确认回复对象和发件账户正确。相同主题的无引用邮件不应误合并。
3. 写信时在 To / Cc / Bcc 输入本机历史联系人，使用上下键及回车或 Tab 填入；已有地址保留，重复地址不在其他字段重复推荐。
4. 搜索正文中的中文词、附件名称和已提取内容；在条件面板叠加账户、文件夹、状态及日期。状态应包含已发送、草稿箱、已归档、已删除，明确选择草稿箱后可从结果继续编辑原草稿。
5. 日期入口打开紧凑日历，年月居中，翻月按钮对称，星期与日期列对齐，无多余底框和两侧大块留白。检查年份、月份、今天、清除和返回；选择后关键词与其他条件保留，起始日包含、截止日不包含。
6. 使用专门测试数据在“设置 > 高级”创建完整备份，确认 ZIP 校验与数量摘要；恢复前检查备份来源和账户，确认后保留恢复前完整备份。恢复后核对邮件、附件、草稿、分类、AI 结果及待同步状态，凭证仍由本机钥匙串管理。备份未加密且不含钥匙串，支持压缩后 512 MB、解压后 2 GB 以内。
7. 核对写邮件、更改位置、保存备份、搜索及设置操作统一为纯图标文字，保存备份有图标；滚动区继续没有轨道或描边。高级设置可重建索引，数量仅统计本机普通邮件，不把未发送草稿计入普通邮件索引。

## 当前开发版界面复测

从包含 `2c4f2b8` 的源码运行 `./script/build_and_run.sh`，使用 `dist/Boxmail.app` 检查以下变化；版本号仍显示 0.0.13 / build 14。

1. Logo 位于窗口按钮下方、靠左与导航对齐；写邮件入口固定在 Logo 下方，账户及导航滚动时仍可见。
2. 邮件列表四项筛选标签完整单行显示，选中项使用浅蓝底和蓝字；在约 1150 pt 窄窗口及 294 pt 邮件栏中逐项切换，并检查焦点下划线与其他控件一致。
3. 日期面板的年月间距增大，两侧空白收紧，标题与下拉箭头整体居中；月份菜单、翻月和日期回填仍可使用。
4. 附件类型及写信的语气、长度筛选采用相同选中风格，紧凑标签没有挤压或溢出。

以上为复测步骤。当前本机验证范围见 [界面检查记录](UI_REVIEW.md)，不表示已在另一台 Mac 完成验证。如出现问题，记录 macOS 版本、设备芯片、源码标识、操作步骤和界面错误。截图和日志请隐藏授权码、API Key 和无关邮件内容。
