# 配置导出与导入

高级设置在“完整备份与恢复”上方提供独立的“配置导出与导入”，用于迁移账号和偏好配置。此功能已随 0.0.15（build 16）发布，源码、日常开发 App 与 Release ZIP 同步，见 [发布说明](V0_0_15.md)。

## 导出范围

JSON 保存已配置的真实邮箱账号，包括名称、地址、用户名、IMAP / SMTP 主机、端口、加密方式和已保存的授权码；同时保存 AI 地址、模型、思考等级、超时、启用状态、API Key、自定义提示词、邮件签名、同步、阅读和其他偏好。演示账号不导出。

点击“导出配置…”选择保存位置。导出主动从系统钥匙串读取凭证，需要时由 macOS 请求授权；取消或读取失败不替换目标文件。设置页尚未应用的修改不纳入导出，请先点击“应用”。按用户要求，JSON 不加密，包含授权码和 API Key，请妥善保管；文件在本机以仅当前用户读写的权限保存。

邮件、附件、草稿、AI 结果、活动记录、模型列表缓存和本机数据保存位置不包含在配置文件中。需要迁移这些数据时，继续使用“完整备份与恢复”；完整备份不包含钥匙串密钥。

## 导入与合并

点击“选择配置…”打开 Boxmail 导出的 JSON，检查预览中的邮箱、新增与更新数量、AI 地址和模型，再点击“导入配置”。预览不显示授权码或 API Key 的具体内容；取消时保留原配置。

同邮箱地址忽略大小写后匹配已有真实账号，更新连接参数和授权码，保留原账号 ID、同步历史及本机邮件。新邮箱添加为新账号，其他账号及已有邮件、附件、草稿保留。AI、签名和偏好使用文件中的配置；文件内未配置的密钥保持为空，需使用相应服务时再补充。当前存在多个相同邮箱账号时，先在账号设置中整理后再导入。

导入不增加应用内授权步骤，也不读取旧钥匙串凭证。客户端先保存新的凭证项，后端在同一事务提交账号、设置及凭证引用；校验、写入或配置冲突失败时保留原配置。导入成功后先采用已提交的设置，即使邮件列表暂时刷新失败，点击“应用”也不会写回旧设置。配置预览期间若账号或设置发生变化，需要重新选择文件后再导入。

支持当前格式版本 1、100 个账号及 2 MB 以内的 JSON。签名、端口、服务地址、偏好类型和重复账号均会校验；损坏文件和不支持的格式给出具体提示。数据库结构版本仍为 SQLite `user_version=2`。

## 验证记录

140 项后端测试和 51 项 Swift 测试通过，覆盖导出范围、同邮箱合并、无关数据保留、格式和容量限制、过期预览、ID 冲突、事务回滚、普通保存保留凭证引用，以及配置文件的原子替换和权限。

原生验证使用独立 App、数据目录、钥匙串服务及合成凭证，完成导出、损坏文件错误、取消预览、账号新增和更新、签名与提示词导入、重启后再次导出并核对全部密钥。导入阶段未读取旧凭证，SQLite 不包含密钥明文；日志与截图位于 `artifacts/configuration-transfer/`，完整测试日志为 `artifacts/configuration-tests.log`，均不提交 Git。
