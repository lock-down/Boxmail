## 删除恢复与取消归档

邮件移入已删除前保存来源文件夹和服务器路径；恢复时返回该位置，例如已发送邮件回到已发送。详情按钮和列表右键菜单显示实际恢复目标。已归档邮件提供“取消归档”，同样回到归档前的文件夹；重复归档不会覆盖原始来源。

来源信息随本机记录保存，退出、重启、服务器移动及 UID 变化后继续保留。“归档 → 删除 → 恢复”先返回归档，之后仍可取消归档回到最初位置。相同 Message-ID 的收件与已发送副本优先使用目标 UID 与 UIDVALIDITY 关联，避免把两份邮件的来源混用。同步前撤销移动不会向服务器提交同文件夹移动。

旧版邮件没有来源记录时，优先识别仍保留的服务器路径，再按账户邮箱地址识别已发送，其余回到收件箱。旧版已经同步且来源丢失的邮件无法准确还原最初文件夹。本版不改变 SQLite 结构版本，继续使用 `user_version=2`。

## 清空已删除

“已删除”列表标题右侧增加“清空”。确认文案说明当前账户、永久删除及未显示邮件范围；取消后不做更改。确认后清空当前账户的整个服务器已删除文件夹，包括未下载的邮件，不受搜索、筛选或分页影响。

真实账户需要连接 IMAP，先执行待处理的恢复和移动，避免把已恢复邮件一并清空；服务器确认后清理本机对应记录、任务与无引用附件。其他账户、其他文件夹及仍被草稿或邮件引用的附件保留。同步、清空及冲突的账户和 AI 操作使用账户互斥检查，失败时显示具体原因。演示账户仅操作本机。

## 计数与本机数据

已发送侧栏显示当前账户的本机邮件总数，空文件夹显示 0；移动、恢复和取消归档后即时更新。

列表底部按当前账户、当前文件夹实时计算本机缓存，不受搜索、筛选和当前分页影响。服务器数量单独标明为“上次同步服务器共 … 封”，避免将同步快照当作移动后的本机数量。“设置 > 高级 > 本机数据”显示全部账户合计、各账户合计及文件夹明细，可与列表逐项核对；附件统计包含邮件及本机草稿引用的附件文件。

## 无边框滚动条

原生滚动区统一移除轨道、描边和内容焦点边框，只绘制圆角细滑块。覆盖列表、阅读、写信、设置及后续挂载的原生预览；HTML 邮件和表格预览同步使用透明、无边框轨道。邮件选中、滚动或布局变化后继续保持样式。

实现集中在 `ScrollAppearance`、`BorderlessOverlayScroller` 与窗口级 `ScrollAppearanceScope`，通过 AppKit 公开绘制接口保留滚动、拖动、自动隐藏和辅助功能，不修改系统滚动条偏好。具体界面检查见 [UI 记录](UI_REVIEW.md)。

## 验收

`./script/test.sh` 通过 **114 项后端测试、38 项 Swift 测试**。新增覆盖来源持久化、UID 变化、归档与删除链、相同 Message-ID 副本、未缓存服务器邮件、待处理恢复、附件引用保留、接口互斥及新旧数据契约。发布测试日志位于 `artifacts/release-v0012/tests.log`。

原生界面使用独立的两个演示账户、80 封合成邮件和两个附件文件：

- 本机数据合计为 80，主账户 71、副账户 9；主账户收件箱本机 66 与上次服务器 70 分开显示。
- 已发送来源的归档邮件取消归档后回到已发送，侧栏从 3 更新为 4，归档从 2 减为 1。
- 删除恢复按钮、右键菜单及各来源目标正确；清空确认和取消保留邮件。
- 长邮件选中及列表滚动后可见无轨道细滑块，高级设置滚动到底部后样式一致。

原生滚动组件探针检查横纵方向、偏移、动作目标、隐藏指示条，以及原生替换后的样式恢复。前期功能日志、演示数据和探针位于 `artifacts/archive-cache-verification/`；这些本机证据不提交。真实邮箱恢复、取消归档和永久清空的服务器操作使用模拟 IMAP 验证，本轮未在真实邮箱执行清空，也未调用云端 AI 或发送外部邮件。

## 发布产物

开发 App 为 `dist/Boxmail.app`。Release 使用 `./script/package_app.sh` 生成：

- `dist/Boxmail-v0.0.12-macos-arm64-clean/Boxmail.app`
- `dist/Boxmail-v0.0.12-macos-arm64-clean.zip`
- `dist/Boxmail-v0.0.12-macos-arm64-clean.zip.sha256`

ZIP 包含 Release App、Node.js、本机 PPT 组件、生产依赖、使用说明及版本信息，关闭演示数据；不包含个人账户、密钥、邮件、附件缓存和开发测试文件。开发和 Release App 检查版本、构建号、内置后端及代码签名；解压包核对文件完整性、SHA-256，并在独立空数据目录检查首次启动为空。

发布构建和结构记录位于 `artifacts/release-v0012/`，源码、合成测试及文档提交本地仓库并标记 `v0.0.12`。当前没有配置 Git 远程，本次发布为本地标签及分发 ZIP。

此包适用于 Apple 芯片 Mac，声明最低 macOS 14，沿用本机临时签名，尚未使用 Developer ID 签名或完成公证。当前设备的启动检查不代表已验证最低系统或其他设备；首次安装步骤见 [另一台 Mac 测试说明](TESTING_ON_ANOTHER_MAC.md)。
