# UI 调整与检查记录

2026-10-16，对 Boxmail 原生 macOS 界面进行检查与优化，改动纳入本地版本 0.0.5。界面保留现有邮件操作与 AI 流程；后续反馈修复还调整了单封 AI 的流式接收、上下文序列化及连接错误提示，后端接口和存储结构保持兼容。

## 发现与调整

| 检查发现 | 调整方式 |
| --- | --- |
| 蓝色邮件操作和紫色 AI 操作同时强调，层级分散 | 统一使用克制的蓝色，AI 保留明确名称和 SF Symbols；成功、提醒继续使用语义颜色 |
| 摘要及整理页面卡片层层嵌套，数量占据过多空间 | 摘要使用单行统计和单层内容；分类使用紧凑筛选，留出邮件审阅空间 |
| 三栏比例固定，宽屏页面两侧留白过大 | 使用原生可拖动分栏；列表宽度 294 至 380 pt，阅读内容最大 860 pt；摘要、整理等工作页面随窗口展开，保留 28 pt 页边距 |
| 控件尺寸和鼠标反馈不一致 | 通用操作按钮高 32 pt，图标点击范围 32×32 pt；增加悬停、按下和焦点反馈，降低动态效果时关闭反馈动画 |
| 草稿、附件和设置内容在宽屏过度拉伸 | 草稿突出主题和收件人；附件筛选按可用宽度换行；设置内容最大 740 pt，保留原有账号输入布局 |
| 切换账户后邮件列表可能停在原滚动位置 | 账户、文件夹、筛选和搜索上下文变化时重置列表，首封邮件重新可见 |
| 活动记录直接显示内部 AI 任务状态 | 在显示层将已知任务和状态转换为中文，未知记录原样保留 |

## 界面规则

保留系统字体和 SF Symbols，使阅读、表单、系统菜单和键盘操作维持 macOS 的使用习惯。颜色、通用按钮、空状态、页标题和内容宽度集中在 `Sources/Boxmail/Support/DesignSystem.swift`。

侧栏固定 216 pt，导航可滚动，底部状态固定。选中项同时使用背景、文字和选中语义标识，图标、文字和行内空白均可点击。邮件列表使用完整行按钮，保留右键菜单。邮件阅读内容居中，AI 总结在较窄区域将待办与关键信息改为纵向排列。

摘要中的待办与关键信息在宽屏共享可用宽度，关键信息不再固定为 200 pt。标签与值均左对齐，较窄窗口改为上下排列，完整显示长英文主题和分类说明。摘要总览的“收件箱未读”与侧栏共用同一数据来源，垃圾箱、已发送等其他文件夹的未读状态不计入。

邮件工具栏将回复按钮与其他操作分组，图标按钮和图标菜单均占 32×32 pt，组内间距固定。菜单触发器使用固定尺寸，弹出菜单按内容确定宽度，避免随阅读栏拉长。

写信正文和 AI 要求输入框使用同一个轻量 AppKit 文本组件。提示文字与光标共用字体、段落和文本容器起点；滚动条覆盖在内容边缘，仅在溢出时出现，不预留宽轨道。组件继续通过 SwiftUI Binding 保存内容，支持输入法、原生撤销及草稿自动保存。

邮件头可展开收件人与抄送，展开区域按内容增高，最多 120 pt。转发 HTML 表格中的长收件人名单最多显示 160 px，其余内容在名单内滚动；鼠标离开名单或滚到边界后继续滚动整封邮件，原始正文和地址内容不被裁切。

附件预览取消固定左右分栏，改为“AI 理解 / 原文内容”标签，内容最大宽度 900 pt。旧的中文分段结果和新的 Markdown 标题、列表共用排版组件，原文预览压缩连续空行。附件选择、整理范围、数量和发件人使用同一内容宽度菜单；模型等图标菜单固定 32 pt。长名称在菜单中缩写，完整文件名仍在详情与提示中可读。App 包声明本地化支持，系统保存面板使用系统语言，不修改系统语言偏好。

单封邮件 AI 总结、翻译、附件理解和回复继续直接显示在阅读区。附件中心仍负责搜索、预览和下载。三个回复态度、预览、使用后编辑、发送确认，以及智能整理的暂停、续跑、确认与撤销保持原流程。

设置保留七个页面、SSL/TLS 与 STARTTLS 互斥勾选、Low/High/Max 思考等级、超时及可编辑默认提示词。写信保留收件人、抄送、密送、签名、附件、本机保存与 AI 写信，不调整发送行为。

补充检查了用户反馈的四处问题：放大窗口下的摘要页边距、总览与收件箱未读数一致、工具栏两个菜单的内容宽度、长英文关键信息的对齐和换行。正文与 AI 要求输入框分别验证短文本不显示滚动条、长文本可滚动、撤销后恢复原文，以及清空后隐藏滚动条。使用已有演示草稿检查，结束时恢复原有正文并保存关闭。

61 项后端测试和 15 项 Swift 测试通过。新增测试验证 8 个长附件在超过旧截取长度时仍保留全部有效 JSON、流式总结完成、断流后保留原总结及新旧理解文字排版。构建脚本完成原生 App 编译、打包、启动和本机签名验证；`git diff --check` 通过。检查主要使用演示账户及已有结果，未增加真实 AI 请求、发送外部邮件或修改已保存的账号配置。

原生界面已检查实际转发邮件的名单内部滚动，确认滚动名单时外层邮件位置不变；已查看已有附件理解结果、完整宽度预览、内容宽度菜单和系统中文保存面板，并取消下载。邮件脚本仍被禁用，名单布局由客户端可信脚本处理，既有远程图片及正文兼容测试继续通过。多附件修复通过本机模拟服务验证，本轮未重新提交真实邮件和附件到云端。

本轮检查不替代真实邮箱投递、云端模型联调或正式分发验证。当前仍使用原有浅色界面，尚未增加深色主题；Intel Mac、最低系统版本及屏幕阅读器完整流程仍待专项验证。
