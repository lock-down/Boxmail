# Boxmail 使用指南

本指南记录 Boxmail 0.1.12 的操作。安装包里的 `版本信息.txt` 说明版本、架构和源码提交。使用历史安装包时，以同包的更新说明为准。

从 0.1.0 及更早版本升级时，需重新保存授权码和 API Key，或导入此前导出的配置 JSON；应用不会自动读取旧钥匙串。

若旧版本在同步后提示“未能读取数据，因为它的格式不正确”，完全退出后替换为当前版本并重开 App；新版兼容异常字符并自动修正未知附件类型，已有邮件、附件与 AI 结果继续保留，无需删除账户或清空缓存。少量未下载完成的邮件可点击“继续同步”补拉；若仍报错，请导出新版本的诊断日志。

## 安装与首次配置

发布包内置本机服务、Node.js 和运行依赖，无需另装开发工具、Office 或 LibreOffice。项目声明最低 macOS 14；目前验证环境为 Apple 芯片 Mac，最低系统及 Intel Mac 尚未验证。

1. 解压 ZIP，将 `Boxmail.app` 拖到“应用程序”并打开。
2. 若 macOS 阻止首次打开，确认文件来源后，按“系统设置 > 隐私与安全性”中的“仍要打开”及系统提示操作。当前包使用临时签名，尚未完成 Developer ID 签名和公证。
3. 在“设置 > 账号”添加邮箱地址、登录用户名、IMAP / SMTP 主机、端口、加密方式及授权码，测试连接、保存，再同步。
4. 在“设置 > AI”配置现有连接，或点击“自定义 API”添加服务商，填写协议、API 地址、密钥和模型，测试连接后点击“保存”。

当前日常开发版和发布包默认不生成演示邮箱或示例邮件，新数据目录从空账户开始。只有隔离验收模式启用演示数据，演示邮箱不能发送真实邮件。关闭初始化不会删除已有示例数据；已使用过 Boxmail 的电脑继续读取原数据，需要完全隔离时可使用新的 macOS 用户。

尚未添加账户时点击“写邮件”会进入账号设置，添加后再创建草稿。

设置、写信、附件预览、标签管理和自定义 API 面板会按当前窗口调整尺寸；嵌套配置表单可独立滚动，底部操作保持可见。

覆盖升级前先用 Command-Q 完全退出 Boxmail，等待退出完成后再替换 App。关闭时会取消后台任务并等待本机服务释放数据目录；启动时可回收同一安装位置、同一数据目录中确认已失去 App 的残留服务。正在使用目录的另一份 Boxmail 仍会阻止启动。

邮箱通过通用 IMAP/SMTP 接入。SSL/TLS 常用端口为 IMAP 993、SMTP 465；STARTTLS 常用端口为 IMAP 143、SMTP 587。切换加密方式时只联动默认端口，自定义端口保留，两种方式均验证服务器证书。旧版 TLS 勾选对应 SSL/TLS，已有账户无需重新添加。

设置分为「常用、账号、邮箱规则、AI、高级、开发者」。同步、阅读和通知位于「常用」。在「账号」设置默认或单个发信账户的签名，适用于此后新建的邮件、回复和转发。在账号编辑窗口中保存连接参数，在设置底栏保存签名。邮箱规则在各自的编辑窗口中保存。

## 邮箱导航与附件

侧栏提供收件箱、清单、星标邮件、草稿箱、已发送、已删除、已归档、垃圾邮件和已保存视图。窄窗口从左上角打开邮箱导航。双击顶部空白区域可缩放或还原主窗口。

在顶部搜索框输入附件名或内容，再打开来源邮件。点击附件卡片可预览，预览上方可打开原邮件、用系统应用打开原文件或下载。有多个附件时可在同一来源内切换。转发时原附件随草稿保留，可在发送前移除。

ZIP 打开后先显示文件目录。选中文件可查看原文件及已有的单文件分析。包内文件清单和历史分析可按其中的文件来源相互跳转。当前最多列出 100 个文件，允许最多 2048 个目录条目。ZIP 和单个解压文件的上限为 25 MB，可处理的解压内容合计最多 100 MB。完整目录可用原始 ZIP 查看。

## AI 设置与本机凭证

默认连接保留 DeepSeek 的 `https://api.deepseek.com`、`deepseek-flash` 及 Responses 协议，自定义提示词继续使用，旧钥匙串密钥需重新保存或通过配置 JSON 导入。BYOK 指使用自己的 API 密钥；可保存最多 20 个服务商，从“当前服务商”切换，所有邮件 AI 功能共用所选连接。

“模型与连接”用于切换服务商和默认模型；密钥、协议、API 地址与超时位于“连接设置”，缺少密钥时自动展开。“连接设置”和“模型目录”的标题整行均可点击展开或收起。常规输入框按同一宽度对齐，超时保持短输入框；“任务提示词”单独调整各类任务。

点击“自定义 API”，填写唯一的 Provider ID、显示名称、API 地址和协议，然后添加所需模型。Provider ID 以小写字母开头，只用小写字母、数字和连字符，创建后保持不变；每个服务商在本机 `.env` 中使用独立凭证。API 地址填基础路径，远程使用 HTTPS，本机回环地址允许 HTTP。

| API 协议 | 基础地址与能力 |
| --- | --- |
| OpenAI Responses | 按服务商填写基础路径，自动请求 `/responses`；图片及 PDF / PPT 理解需视觉输入，原默认连接还需 Files API，自定义连接内联提交图片。原默认连接保留 Low / High / Max，其他模型按声明选择推理等级 |
| OpenAI Chat Completions | 例如 `https://gateway.example/v1`，自动请求 `/chat/completions`；图片以内联方式提交，模型需支持视觉输入 |
| Anthropic Messages | 例如 `https://api.anthropic.com`，自动处理 `/v1/messages`，地址已含 `/v1` 时不重复添加；图片以内联方式提交 |

“获取模型”会展示候选模型，勾选后加入目录，已有模型的名称和参数会保留。列表按服务商、协议和基础地址分别缓存，失败保留上次成功结果。可通过“添加模型”维护目录，也可从“模型设置”直接输入目录外的模型 ID。超时可设为 10 至 600 秒，服务商需支持所选协议的流式返回。

展开模型行可填写显示名称、上下文窗口和最大输出 token 数，选择文本、图片输入能力，以及启用推理等级。容量支持 `256K`、`32K`、`1.5M` 等写法，1K = 1000；最大输出数不能超过上下文窗口。留空使用默认能力，明确填写输出数会限制单次请求。新自定义模型默认仅支持文本，图片、PDF 和 PPT 理解需按服务商说明勾选图片。

启用推理后，可增删等级并填写它在接口中的实际发送值，例如 High 对应 `high` 或 `max`；Off 留空表示不发送推理参数。模型选择菜单只显示该模型声明的等级。Anthropic 可选择思考预算或自适应推理，须与具体模型能力一致；预算模式按等级分配思考 token，自适应模式使用等级映射。Chat Completions 可按服务商要求选择 `max_completion_tokens` 或 `max_tokens` 作为输出上限字段。

连接、目录、密钥和当前选择需点击“保存”生效，取消保留原设置；成功获取的模型列表缓存独立保留。移除服务商后保存设置会移除其凭证，至少保留一个连接。“测试连接”会实际调用所填服务，可能产生服务商费用。

邮件翻译、「帮我写」、基于原邮件的回复及参考会话的回复各有默认提示词。清空并保存可恢复默认值。升级保留自定义提示词、签名和已有结果。

邮箱授权码和 API Key 保存在当前数据目录的 `.env`，默认路径为 `~/Library/Application Support/Boxmail/.env`。在设置界面保存账户或 API Key 后自动写入，权限为仅当前用户读写（`0600`）。文件为明文，可从“设置 > 高级 > 本机数据 > 显示凭证文件”定位；不要提交到 Git 或分享。服务器地址、模型、提示词和偏好仍保存在 SQLite。

手工编辑时使用 UTF-8，每行一个 `KEY=VALUE`，键名区分大小写并保留 ID 中的连字符。未生成独立引用时，默认 AI 密钥为 `BOXMAIL_AI_KEY`，自定义服务商为 `BOXMAIL_AI_PROVIDER_<Provider ID>_KEY`，邮箱授权码为 `BOXMAIL_MAIL_<账号 ID>_PASSWORD`；账号 ID 可在导出的配置中查看。值可使用单引号包围以保留原文，或使用双引号及 JSON 转义，例如 `\n`、`\"`、`\\`。`#` 是引号外的注释起点，不执行变量替换或 shell 命令；不要在 shell 中 source 此文件。设置保存新凭证和配置导入会生成 `BOXMAIL_CONFIGURATION_<UUID>` 条目，SQLite 保存对应引用；已有引用时优先读取该条目，可在设置界面修改凭证，手工编辑须保留生成的键名。

保存邮箱授权码或修改过的 API Key 时，先写入独立条目，再切换生效引用；请求失败不会覆盖原凭证。若提交成功但响应丢失，应用会检查当前生效状态；暂时无法确认时保留可能生效的条目，并提示重新打开设置核对。保存后即使邮件列表刷新失败，账户和设置仍然生效。

每次同步、发信和 AI 请求都会读取当前文件，手工修改后无需重启。后台同步也可在启动后直接读取，不需要系统授权；邮箱授权码缺失或文件无法读取时，侧栏显示“检查邮箱凭证”，可进入账号设置处理。普通偏好保存不会清空未修改的密钥。

升级不会自动访问或删除旧钥匙串。请在“设置 > 账号”重新填写授权码并保存，在“设置 > AI”为各服务商重新填写 API Key 并保存；也可导入此前导出的配置 JSON。开发启动可通过绝对路径 `BOXMAIL_ENV_FILE` 指定其他 `.env` 文件，界面会显示实际路径。

## 阅读、同步与写信

每次同步先核对服务器邮件数量与 UID 清单，每次最多读取 200 封的轻量元数据。服务器漏返回部分邮件时，自动缩小批次补拉缺项；清单完整后才校准本机缓存，补拉后仍不完整则保留原缓存并提示重试。 多账户同步最多同时运行两个账户，其余排队。单次会话在批次间复用已校验的清单；每批核对数量、文件夹身份与下一封 UID（UIDNEXT），发生变化时重新读取；服务器未提供 UIDNEXT 时，清单最多复用一分钟。新的同步会话也重新核对。

各文件夹每批最多下载 200 封缺失或需修复的正文，并在约 20 秒预算后让出；后台会自动轮转未完成的文件夹，直到本次范围内的历史邮件全部补齐，无需每批手动继续。列表底部持续显示已下载与服务器总数，正常同步及批次结束不弹窗。顶部同步按钮在运行时提供“停止本次同步”，已下载邮件保留，下次同步会自动继续。超过 1 MB 的邮件优先分段下载；服务器忽略分段、返回错位数据或报告大小不一致时，自动重试并回退完整原文。已完成的邮件逐封保存，后续同步继续补齐。一处文件夹失败后会继续处理其他文件夹，错误在对应列表显示。列表每页 100 封，“显示更多邮件”位于滚动列表末尾；失败或停止后，可从底部状态栏重新发起同步。网络恢复和电脑唤醒时会尝试同步；退出、睡眠或离线期间不会持续收信。邮件状态未变化时不重复写入，也不重新生成搜索索引。

清单阶段显示已读取与服务器总数，正文阶段显示已下载与总数。邮件解析以及 PDF、Word、Excel、PPT 附件提取在独立解析进程运行，支持超时与取消。单个解析进程崩溃或超过内存预算时，原附件仍保留，继续处理其余邮件；未完成解析的正文会延后重试。一个账户启动超时不会阻断其他账户的进度查询；查询连续失败三次后，应用请求停止本次同步并退出忙碌状态，保留已下载邮件。后端连续 120 秒没有阶段或进度更新时也会中断任务，可检查网络后重试。

若网页版能看到历史邮件、Boxmail 却没有，请先检查服务商的收取范围。网易邮箱在“设置 > POP3/SMTP/IMAP”中将“仅收取最近 30 天”改为“收取全部邮件”并保存，再同步。旧的已发送邮件也受此设置影响；客户端只能同步服务器当前开放的邮件。QQ 邮箱也可在网页版“设置 > 账户 > 收取选项”检查范围。[网易官方帮助](https://help.mail.126.com/searchFAQ.do?m=search&word=%E6%94%B6%E4%B8%8D%E5%88%B0%E9%82%AE%E4%BB%B6)

HTML 邮件支持表格、CID 内嵌图片和外部图片。默认屏蔽远程图片，可点击“加载本封邮件图片”或在阅读设置中调整；邮件脚本、表单和嵌入页面会移除，链接通过默认浏览器打开。

会话按同账户的 Message-ID、In-Reply-To 和 References 建立时间线，不按相同主题直接合并，也不跨账户合并。当前选中的邮件固定在最上方，其余往来按时间倒序显示，较新的邮件在前；选择旧邮件时也会将其置顶。回复发送成功后，本机副本即可关联原会话，无需等待服务器同步。每次载入 100 封，正文与附件按需读取，引用可展开。顶部操作针对当前选中的邮件，其他往来可逐封回复或打开；会话只包含已缓存历史，可使用“会话 AI”总结往来进展、未决事项及下一步，并生成上下文回复预览。

邮件列表、草稿列表和会话折叠项的缩略预览共用签名过滤规则，排除可识别的签名分隔段、HTML 签名区和移动设备落款，保留历史引用。草稿箱及关联回复草稿只有签名或正文为空时，显示“尚未撰写正文”。已有缓存刷新后即可生效，无需重新同步；完整正文、签名和引用仍保留。搜索范围继续包含原文，若关键词只出现在被过滤的签名中，结果仍会列出该邮件，缩略改用不含签名的预览。

阅读区顶部的“转发”与“回复”并列显示；回复右侧的下拉菜单仅提供“全部回复”。

点击邮件头的“发送至”可展开收件人、抄送和密送，长名单展开为 240 pt 高的滚动窗口，短名单按内容高度显示。鼠标停在名单内即可用滚轮或触控板滚动，无需先点击；移到正文后立即滚动正文，无需先滚完整份名单。鼠标仍在名单内时，到达顶部或底部后继续滚动会移动外层正文，也可拖动滚动条及选择复制地址。HTML 正文的表格、`Original / To` 列表、换行式引用及纯文本引用内的长名单使用相同的折叠组件，转发预览和草稿搜索详情也保持一致。折叠仅用于本机展示，不改变原邮件或转发快照。

从清单、附件预览或历史结果打开原邮件时，会切换到对应账户与文件夹，自动滚动并高亮目标邮件，阅读区同时显示同一封原文。较旧邮件不在首批列表中时，会先显示目标行；重复打开同一封邮件也会重新定位。

### 列表、多选与快捷键

邮件列表默认按发件人聚合，同一账户内的实际发件邮箱忽略大小写后归为一组；同名但不同邮箱、不同账户以及缺少发件邮箱的邮件各自保留。每组显示最新邮件及匹配邮件总数，按最新邮件时间倒序排列；展开后，较早邮件也按时间倒序显示，超过一页可点击“显示更早邮件”。搜索和筛选同时作用于组计数及组内邮件。

点击发件人左侧箭头展开或折叠，点击邮件行阅读正文；列表标题右侧的“发件人”菜单可切换为“逐封显示”，选择会保留到下次启动。选中聚合行时，右方向键展开、左方向键折叠。从附件或摘要打开较早邮件时会自动展开并定位。草稿搜索继续逐封显示。

全选和批量操作仅包含当前显示的邮件，折叠组内未显示的邮件不会被一并选中。折叠正在选择的旧邮件时，选择会回到该组最新邮件；若还选有其他组的邮件，则保留其他选择。

单封回复、转发及翻译快捷键仅作用于正在阅读的一封普通邮件。多选、草稿搜索结果、设置或写信窗口中会禁用这些命令；已有写信窗口时，新建命令也会禁用，避免替换当前草稿。

邮件栏可在 294 至 560 pt 之间拖动调整；窗口宽度不足 1080 pt 时收起常驻侧栏，可从左上角打开邮箱导航，旁边仍可直接写信。邮件行采用一行预览，将附件与星标放在主题旁，标签显示在预览右侧。多个标签可从标签菜单查看，摘要集中在清单。预览优先显示可读文字，省略混在文字中的裸链接；只有链接的邮件仍保留链接。正文、搜索索引与发送内容不受影响。账户名称与邮箱地址相同时，侧栏改用服务商或域名作为名称，完整地址可悬停或在账户菜单查看。

在邮件列表中，按住 Shift 选择连续范围，按住 Command 点击可离散多选；标题旁的选择按钮或 Command-A 仅全选当前已加载的邮件，不会自动选中未加载的历史。多选后，列表上方显示批量归档、移到已删除、标记和标签操作；右键菜单也作用于所选邮件。每批最多 1000 封，草稿搜索结果不参与邮件批量操作。

| 按键 | 操作与范围 |
| --- | --- |
| 上／下方向键 | 列表聚焦时切换邮件；配合 Shift 连续选择 |
| Command-A | 列表聚焦时全选已加载邮件 |
| Control-Command-A | 列表聚焦时归档所选邮件 |
| Delete | 列表聚焦时将所选邮件移到已删除 |
| Command-Shift-U | 列表聚焦时切换所选邮件的已读状态 |
| Command-Z | 撤销当前会话最近一次手动邮件操作；文字编辑时沿用编辑器的撤销 |
| Escape | 列表聚焦且多选时取消选择 |
| Command-F | 聚焦顶部邮件搜索框 |
| Command-N / Command-R | 写邮件／回复 |
| Command-Shift-T | 翻译当前阅读的邮件 |
| Command-Shift-F / Command-Shift-R | 转发／同步所有账户 |

批量操作按账户分别提交，每个账户内使用同一事务。某账户的邮件不存在、状态冲突，或该账户正在同步且操作需要修改服务器状态时，该账户的整批操作失败；其他账户仍可成功，界面分别显示失败原因，并保留成功项的撤销。操作后底部显示结果和“撤销”；撤销只还原本次改动的字段，保留其他编辑。撤销记录只在当前会话保存，重启后不保留；相关状态被后续操作改变或邮件已同步为新的身份时，撤销会拒绝覆盖，可从已删除或已归档中恢复。自动标记已读不覆盖手动操作的撤销记录，永久清空已删除邮件不支持撤销。

邮件列表底部显示上次同步时间；旁边的信息按钮展开本机缓存量、上次服务器数量与搜索范围说明。自动补齐期间隐藏手动继续入口；同步失败、无进展或停止后，保留重试与继续入口。单封正文持续不返回时，先继续下载同一文件夹的其他历史邮件，健康邮件补齐后自动再补拉一次；仍失败的邮件保留为待下载，不保存残缺正文。连续三封正文下载或临时解析失败时暂停该文件夹，继续处理其他文件夹，避免服务器不可用时不断重连。过深的 HTML 降级为可读文字；确定无法解析的邮件保留邮件头与原始 EML 附件，可下载或删除，不再反复解析。服务器文件夹删除或失去特殊用途标记后会自动更新映射；失效路径的待操作会取消并记录活动，临时网络失败的操作保留重试。剩余数量和错误留在列表中，下次同步重试缺失邮件。

### 写信与草稿

点击侧栏“写邮件”或按 `Command + N` 新建本机草稿。空白的抄送和密送默认收起，从收件人行右侧的“抄送 / 密送”展开；已有地址的字段会保持可见。「帮我写」从正文格式栏打开浮层，正文保持原有高度。未编辑的新邮件关闭后不会新增空白草稿。To / Cc / Bcc 输入姓名或邮箱关键词后显示当前账户历史邮件和草稿中的联系人，支持上下键选择、Enter 或 Tab 填入、Esc 关闭；跨字段去重，只替换当前地址片段。空输入时用鼠标或 Tab 切换收件人、抄送和密送，不弹出空候选面板；无匹配或中文输入法组合期间保持正常编辑。联系人填入后写作 `姓名 <邮箱>`，多个地址可用逗号、分号或换行分隔。

“全部回复”会处理 Reply-To、原 To / Cc、地址去重和自身地址排除，转发沿用独立的引用语义。短正文的个人签名位于编辑区底部，长正文时跟随文末；单击「签名」分隔线以上的留白，光标定位到正文末行。单击「签名」标签或分隔线可从签名开头编辑，单击文字可定位到所在行。拖选、Shift 选择和撤销沿用原生行为。分隔线和标签仅用于写信界面，发送时正文与签名连续呈现。已移除的签名不会自动补回。

正文上方的格式栏依次提供粗体、字号、文字颜色、项目符号列表、编号列表及链接。字号菜单提供 8 至 72 pt 的常用字号；文字颜色菜单提供预设颜色、“默认”和“自定颜色…”。自定颜色支持 RGB 滑杆、数字输入、`#RRGGBB` 色值和屏幕取色。点击“应用颜色”生效。选中文字时只修改选区，未选中文字时用于后续输入；跨越不同字号或颜色的选区显示混合状态。字号与颜色不影响邮件阅读设置。

选中文字后点击粗体或在正文中按 Command-B；Command-K 打开链接输入，支持完整的 HTTP、HTTPS 和 mailto 地址。列表编号和项目符号跟随该项开头文字的字号与颜色，空白项延续上一行的字号，折行缩进按标记宽度调整。列表按 Enter 继续下一项，空白项再次按 Enter 退出列表。格式会随草稿保存及服务器草稿同步保留，发送保留 HTML 与纯文本两种正文；粘贴普通文字按纯文本插入，文件和图片仍作为附件处理。

HTML 邮件转发时，编辑区上方可填写转发说明，下方“转发原文”保留原邮件的表格、字体、配色、链接与图片布局；原文作为独立快照保存，编辑说明或插入 AI 草稿不会改写原邮件。发送同时包含 HTML 和纯文本，内嵌图片转换为邮件内的 CID 图片；预览中的外部图片继续遵循阅读设置，默认按需加载。旧转发草稿的引用内容完整且未修改时，会恢复为排版原文；已编辑的旧引用继续保留原文字，避免覆盖修改。纯文本转发也单独保存完整原文，编辑说明不会触发原文截断。可编辑正文超过 500,000 个字符时会拒绝保存并提示缩短，不会静默丢失尾部。

服务器上移走或删除的邮件保留恢复信息 30 天，每个账户合计最多 2,000 条，按最近时间保留；超过期限或数量上限后清理记录及未被其他邮件或草稿引用的附件。

转发发送时为附件保存独立副本，原邮件和已发送邮件均可查看、预览和理解附件，删除其中一封不会影响另一封。旧版共享附件会在对应文件夹同步时修复。

正文支持 `Command + V` 粘贴 Finder 文件和剪贴板图片，也可从底栏点击“添加附件”选择文件。普通文字仍粘贴到正文，文件夹不能作为附件，单附件限制 25 MB。草稿先自动保存在本机，列表只加载轻量预览；点击继续编辑时再读取完整正文及转发原文，加载失败会保留原稿并提示重试。

真实账户的草稿随邮箱同步，也可从草稿箱或写信格式栏点击“同步草稿”。应用使用服务器的草稿文件夹；缺少该文件夹时创建 Boxmail Drafts。离线期间继续本机编辑，联网后再同步。服务器草稿中的密送和附件会一并保留；正文与附件编码后的单份草稿上限为 25 MB，超过时保留本机内容并提示缩小后重试。演示账户只保存在本机。

同步遇到单封服务器草稿无法读取时，会提示警告并继续其他草稿，本机原稿保留；服务器替换版本暂时不可读时，不会将原稿误判为已删除。同步期间仍可编辑和关闭写信窗口。

如果本机与其他客户端同时修改，草稿箱分别保留服务器版本和本机冲突副本；核对后可以继续编辑，或点击“同步为新草稿”分别保留。服务器草稿被删除或文件夹身份改变时，本机内容会保留并等待处理，不自动重新上传。旧编辑窗口保存时遇到版本变化会拒绝覆盖，可“另存为新草稿”保留当前编辑内容。

关闭写信窗口会先保存当前修改。更换发件人后，草稿随发件账户移动，正文和附件一并保留。旧账户的服务器草稿会在后续同步时清理。保存关闭或发送期间，发件账户、收件人和正文暂时锁定。正在编辑时，新建、回复或其他草稿请求不会替换当前窗口；迟到的回复结果也不会覆盖新草稿或恢复后的数据。

从底栏选择“发送”或“定时发送”，核对内容后确认。若显示结果不确定，先检查服务商已发送文件夹及收件情况，再决定后续处理；应用不会自动重发。同一草稿的并发提交会被阻止。投递失败时，在草稿箱查看原因，可取消发送或重新安排。SMTP 接受后归档失败也可能显示提示，不能据此再次发送。草稿发送期间不能移除所属账户；移除账户会清理该账户的本机缓存及待关联邮件附件，保留其他账户仍引用的附件和服务器邮件。

### 恢复、归档与计数

“已删除”中的恢复和“已归档”中的取消归档会回到操作前的文件夹，按钮及右键菜单显示目标。归档后删除再恢复，仍可继续取消归档。旧记录缺少来源时优先识别服务器路径，再按发件地址区分已发送，其余返回收件箱；来源丢失时无法准确还原。

“已删除”右上角的“清空”在确认后永久删除当前账户整个服务器已删除文件夹，包括未下载或未显示的邮件，不受搜索与筛选限制，也不可撤销。其他账户、文件夹及仍被引用的附件保留。清空期间保存的账户名称、签名和连接设置继续保留。

侧栏邮箱项在数量大于 0 时显示计数（为 0 时隐藏），其中已发送数和同步详情中的缓存数按当前账户、当前文件夹实时计算，不受搜索与筛选影响；服务器数单独显示为上次同步快照。“设置 > 高级 > 本机数据”可核对全部账户和文件夹明细，附件数包含本机草稿引用的文件。

删除草稿会清理不再被其他邮件、草稿或保留记录引用的附件，并在下次成功同步时清理对应的服务器草稿；发送成功后也会安排清理远端草稿。服务器不支持 UIDPLUS 时不会执行可能影响其他草稿的整箱清理，会保留旧副本并提示手工处理。多次无法核对服务器草稿身份时，也会保留待处理记录并提示人工检查。发送后原文和附件由已发送邮件持有，隐藏的草稿仅作为发送回执。

## 翻译与帮我写

**读信。** 点发件信息下方的「翻译」或按 Command-Shift-T。当前语言已有译文时会直接显示，首次翻译只提交主题和可翻译正文。译文保留段落、表格、链接和图片位置。点「显示原文」可随时切回，译文可复制。

翻译设置的「译为…」按来源邮箱记忆，初始为简体中文。菜单中的「自动翻译外语邮件（Auto）」默认关闭。开启后，打开来信时会优先使用对应语言的完整译文。缺少译文时先在本机识别正文语言，明确为外语时才提交给所配置的 AI 服务商。同语种、难以判断的混合语言、链接或代码为主的邮件保留原文，可手动翻译。生成期间保留原文，失败可就地重试。当前阅读中主动切回原文后会保留此选择。

**写信。** 点正文格式栏的「帮我写」，或选中文字后从右键菜单打开。可填写要求或选快捷动作。点击「写作选项」整行展开，可选标准商务、简短确认、友好沟通、条理汇报，或选用「我的风格」。点「自定义…」可调整语气、篇幅和行文要求，选择「仅本次使用」或填写名称保存为预设。下次写信沿用上次选择的预设。输出语言可选英语、法语等翻译所支持的语言。回复默认跟随来信，改写默认沿用待改写文字，新邮件默认跟随写作要求。候选在浮层内预览，可返回修改要求或采用到当前草稿，选区或正文被替换后可用 Command-Z 撤销。

| 草稿状态 | 提交给模型的材料 | 采用动作 |
| --- | --- | --- |
| 选中可编辑文字 | 选中的文字和本次要求 | 替换选区，保留外部文字和格式 |
| 已有可编辑正文 | 正文和本次要求 | 替换正文，保留账户签名和转发原文 |
| 空白回复或转发 | 原邮件主题、正文和本次要求。回复可另选「参考会话」 | 填入正文并保留当前回复对象和附件 |
| 空白新邮件 | 本次要求、已有主题和写作偏好 | 填入草稿。主题为空时可采用候选主题 |

参考会话使用同一账户中按引用链关联的已缓存邮件。生成时可继续编辑。采用之前会校验草稿内容、格式和已使用的原邮件或会话。草稿有签名时，采用完整候选后可在签名前的正文空行续写。发送继续由用户确认。

## 预览附件与历史结果

已保存的整封分析、会话结论、旧版回复预览和问答可从来源邮件的「更多邮件操作 > 历史结果…」查看，含来源的记录可打开对应邮件或附件。单文件和压缩包已有分析时，预览中显示「历史分析」。查看这些结果只读取本机记录。

附件默认打开原文件预览。PDF 使用 PDFKit，Word、PPT 与其他支持格式使用本机预览。XLSX 展示字体、边框、单元格合并与内嵌图片，最多显示前 10 个工作表、各表 400 行和 60 列。特殊版式和超出预览范围的内容可用「打开原文件」核对。

## 搜索

顶部搜索框搜索邮件及其附件内容，支持关键词、英文双引号短语及组合条件，也可打开旁边的条件面板。搜索时显示独立的“邮件搜索”上下文，可返回原来的页面；按名称或内容匹配附件时，结果行显示对应的来源邮件。正文、往来地址、主题、分类、附件名称和提取内容、译文及已收录的 AI 结果可检索；中文支持两字词及句中子串。

| 条件 | 示例与语义 |
| --- | --- |
| 发件人 | `from:wang@example.com`，匹配姓名或邮箱 |
| 收件人 | `to:finance@example.com`，同时检查 To / Cc / Bcc |
| 抄送、主题、分类 | `cc:team subject:合同 category:审批` |
| 日期 | `after:2026-10-01 before:2026-11-01`，起始日包含、截止日不包含 |
| 状态 | `is:unread`、`is:read`、`is:starred` |
| 附件 | `has:attachment` |
| 账户 | `account:me@example.com`，支持完整邮箱、唯一名称或 ID |
| 文件夹 | `folder:sent`，支持 inbox、sent、archive、trash、drafts、spam 及中文名称 |

多个条件按同时满足组合，例如 `"采购合同" from:"王敏" folder:inbox`。明确的账户条件优先于侧栏选择；无效日期、未知条件、引号未闭合或账户歧义会显示错误。

条件面板的日期日历支持翻月、年月菜单、今天与清除，按本机时区处理，选择后保留其他条件。状态菜单中的已发送、草稿箱、已归档、已删除与文件夹同步；未读、已读、星标可叠加文件夹。

明确选择草稿箱时搜索本机未发送草稿，日期取最后更新时间，可继续编辑原草稿；已发送记录和服务器草稿不计入。普通邮件索引数量不包含这些草稿。

搜索和会话只覆盖本机已缓存内容，未下载历史需继续同步。“设置 > 高级 > 本机搜索索引”可检查并重建派生索引。索引在后台逐封更新，刚同步或修改的邮件可能稍后出现在关键词结果中。单封索引失败会跳过并记录活动，可再次重建，不影响其他邮件、原文及附件。普通邮件每封最多索引 262,144 个字符；草稿正文、转发文字和每个引用附件最多取前 65,536 个字符，单草稿合计最多 262,144 个字符。草稿列表按需加载完整正文，超出搜索范围的原文仍完整保留。

## 清单、邮箱规则与活动记录

**收件箱和保存视图。** 账户菜单选择「所有账户」即可统一浏览。邮件行及阅读区标明原账户，回复使用原邮件账户。标签可与未读和有附件筛选组合。点书签保存当前范围，侧栏可打开、更新或移除已保存视图。

**待办和延后。** 在邮件菜单中选择「加入清单」可添加手工事项。在清单内可勾选、重新打开，或从事项菜单编辑标题、状态、提醒及延后时间。直接显示来信中的期限，也可手动安排提醒。标为「无需处理」的摘要待办可即时撤销。关联回信会在事项旁显示「已收到回复」，是否完成由你决定。延后的会话在到期或取消后回到普通收件箱，期间仍可搜索。到期通知可打开对应事项，通知和角标在「设置 > 常用 > 通知与角标」中设置。

**按标签查找邮件。** 在收件箱打开「标签」筛选，或从邮件的标签菜单为一封邮件勾选多个标签。多选时使用「添加标签」或「移除标签」。删除一个标签会保留邮件和其他标签。旧保存视图和邮箱规则继续沿用各自的分类条件。

**试用标签条件。** 在「管理标签」保存一句匹配条件，点击「试用条件…」，选择邮箱和邮件。先核对命中的主题，再点「应用标签」。要在整理邮件时使用该条件，从「启用的邮箱…」选择账户。手工移除过的标签仍会被排除。

**整理选中的邮件。** 在清单点击「整理邮件…」，选择一个邮箱及已缓存的邮件，提交前查看会发送哪些内容。任务结果、用量与失败重试位于「活动记录」。未启用标签条件时，提交主题和正文。启用时也会提交发件人和匹配条件。

**自动整理新邮件。** 在清单菜单打开「新邮件自动整理…」，选择邮箱并确认。离线时会等待下次连接建立新信起点。关闭后停止提交排队中的自动任务。已有结果保留，已提交的请求可能已经计费。升级后，旧版含 AI 动作的自动规则整条暂停，可在「设置 > 邮箱规则」查看。

**摘要的移除与恢复。** 从摘要行菜单选择「移除摘要」，原邮件和单独收录的事项保留。可即时撤销，也可打开清单菜单的「已移除摘要」逐项恢复。重新生成摘要时沿用已有的移除或恢复状态。

**规则、记录和用量。** 在「设置 > 邮箱规则」配置匹配条件和邮箱动作，点击「预览匹配」，核对后确认运行。纯邮箱规则可按创建顺序自动运行。含旧 AI 动作的规则保留原设置，可移除旧动作并保存为普通邮箱规则。顶部「活动记录」可查看逐封处理结果、来源、失败项、暂停和邮件状态撤销，还可查看模型、耗时及服务商返回的用量。

确认普通发送后有 10 秒等待窗口，可在草稿箱点击「取消发送」。定时邮件也留在草稿箱，可以继续编辑、改期或取消。打开待发送邮件时会暂停投递。保存并关闭后，尚未到期的等待计划会恢复，已过发送时间的邮件保持暂停，可重新选时间。已发出的邮件在「已发送」查看。

写信底栏的「定时发送」提供自定义时间及预设。定时发送、改期和跟进沿用搜索月历。定时发送和改期可直接输入小时和分钟，也可用两侧按钮调整。跟进提醒和稍后处理从下拉列表选整点，点「完成」采用，再点「保存」提交。切换日期保留已选时刻，预设先显示实际日期时间。开始 SMTP 提交后不再提供撤销投递；结果不确定时先核对已发送邮箱。计划记录实际时间和时区，只在本机运行时执行；退出或睡眠后恢复运行时处理到期计划。备份恢复的待发计划暂停，检查后重新安排。

## 数据保存与迁移

默认目录为 `~/Library/Application Support/Boxmail/`：`boxmail.sqlite` 保存邮件、草稿、设置、模型列表及 AI 结果，`attachments/` 保存附件。缓存和备份未加密，凭证单独保存在同目录的 `.env`（或 `BOXMAIL_ENV_FILE` 指定文件）。

| 方式 | 入口与用途 | 是否包含密钥 |
| --- | --- | --- |
| 配置 JSON | 设置 > 高级 > 配置导出与导入；迁移账号、AI、提示词、签名和偏好 | 包含已保存的授权码和 API Key，未加密 |
| 完整 ZIP | 设置 > 高级 > 完整备份与恢复；保存数据库、附件及校验清单 | 不包含 `.env` 凭证 |
| 更改位置 | 设置 > 高级 > 本机数据；下次启动迁移整个本机数据目录 | 包含数据目录下的 `.env`；外部指定文件不移动 |

### 配置导出与导入

配置操作需要本机服务启动成功。若按钮不可用并提示数据目录占用，先关闭设置，在主窗口重试启动；不要删除数据目录中的锁文件或数据库。旧版残留进程无法自动识别时，在“活动监视器”中退出对应的 Boxmail 本机服务，或重启 Mac 后再打开 App。

先保存设置，再重新打开设置，点击“导出配置…”选择 JSON 保存位置。导出包含所有已配置服务商，即使当前未选中或 AI 已关闭；只从本机 `.env` 读取已保存的真实邮箱账号及这些服务商的凭证。仅保留自定义服务商时，不读取旧默认连接的密钥。取消或读取失败不会替换目标文件；文件以仅当前用户读写的权限保存，包含明文密钥，请妥善保管。

选择 JSON 后先检查账号新增、更新数量、当前 AI 选择，以及邮箱 IMAP/SMTP 地址、端口、加密方式、登录用户名和每个 AI 服务商的地址、协议、模型数量及凭证处理方式，再确认导入；预览不展示密钥内容。邮箱地址忽略大小写后合并，已有账号 ID、同步历史和邮件保留，新邮箱新增，其他账号及邮件、附件、草稿保留。AI、签名和偏好按文件替换，非空凭证会创建新的条目。文件中的空密钥与空授权码仅在服务地址、协议及邮箱登录身份与本机一致时保留已有凭证；变化时会解除绑定，并在导入结果中列出需重填的邮箱授权码或 AI Key。

导入不读取旧凭证；校验、写入或冲突失败保留原配置，并清理本次写入的临时凭证。成功提交后即采用新设置，即使列表刷新失败，后续“保存”也保留导入内容。若提交响应丢失，会再次检查生效状态；暂时无法确认时保留可能正在使用的凭证，按提示重新打开 App 后检查。预览期间配置改变时需重新选择文件；已有多个同邮箱账号时先整理账号。

支持格式版本 1 和 2、最多 100 个账号及 2 MB JSON。含 BYOK 服务商的配置使用版本 2，包含独立密钥、模型 ID 与显示名称、上下文窗口、输出上限、输入类型、推理映射和协议兼容参数，并保留当前服务商、模型、超时及开关。旧版单连接配置仍可导入。文件不包含邮件、附件、草稿、AI 结果、活动、独立模型缓存和本机数据位置；完整迁移可分别使用配置 JSON 和完整 ZIP。

### 完整备份与恢复

ZIP 包含一致性 SQLite 快照、登记的附件，以及数量、字节数和逐文件 SHA-256 清单。恢复前先校验文件和关联，展示摘要并确认；最终恢复还会核对文件是否变化。同步、发送或 AI 任务期间不能恢复，维护期间拒绝并发写入。

邮件内的总结和待办、摘要的收录或移除状态、原排版译文、多服务商及模型参数，以及保存视图、跟进、延后、规则与处理记录、AI 用量、写作风格、发送计划、历史问答、历史附件分析及翻译偏好均随完整备份保存；恢复不会把已移除摘要自动重新收录。恢复后清除此前的预览缓存、列表撤销和多选状态，再从备份数据读取结果，恢复前发出的旧请求不会覆盖恢复后的数据。

恢复前自动生成 `backups/before-restore-*.zip`，失败则停止。恢复失败回滚、清理本次暂存附件和自动备份并保留原数据；成功后后台重建索引，中断的发送转为待确认，整理和附件任务转为暂停，单封 AI 任务标为失败。核对账户和待同步更改后再同步服务器。

ZIP 不含 `.env`，恢复也不修改当前凭证文件或数据位置。备份中的凭证引用不会直接沿用；仅当 AI 服务地址、协议或邮箱身份与服务器连接参数和本机一致时，才保留本机现有绑定。新增账号或地址变化后需在设置中重新填写密钥与授权码，恢复结果会列出需重填的邮箱授权码及 AI Key，并标明对应设置位置，活动记录也会提示。跨电脑恢复后请另行导入配置 JSON 或填写凭证。附件恢复支持数据目录位于其他本地磁盘。压缩文件上限 512 MB、解压内容 2 GB、数据库 256 MB、单附件 50 MB；登记附件缺失时拒绝生成残缺备份。更大数据集可退出 App 后复制整个数据目录及 SQLite 关联文件，凭证另行管理。

### 更改数据位置

选择本机或已挂载本地磁盘的空文件夹，保存设置后重启。启动时复制一致性数据库、附件、数据目录下的 `.env` 和已有备份，更新附件路径，确认后切换，原目录保留。非空、互相包含、空间不足或文件缺失时停止迁移，继续原位置。

外置磁盘缺失时显示重试入口，接回后继续使用，不会新建空邮箱。开发环境变量 `BOXMAIL_DATA` 可覆盖本次启动位置，不执行已保存的迁移计划，也不改写日常设置。`BOXMAIL_ENV_FILE` 指定的外部凭证文件不随数据目录迁移。

## 开发者日志

打开“设置 > 开发者 > 导出诊断日志…”，选择保存位置，生成 ZIP。同步正在运行、本机服务未连接或请求超时时，仍可导出已经保存的日志；导出无需等待同步结束。复现问题后尽快导出，并同时记录操作步骤与大致发生时间，方便关联记录。

日志自动记录同步排队、连接、清单、下载、解析、完成、失败或取消等关键事件，以及本机 API、模型请求的错误类型、状态码和耗时。后端每 30 秒记录进程内存、CPU 时间及事件循环延迟，帮助判断资源占用。文件保存在当前数据目录的 `logs/`，应用与后端各保留当前文件及两份轮转文件，每份约 1 MB；较早记录会被覆盖。

ZIP 只包含这些日志、版本和系统信息、匿名化同步状态与说明文件，不包含 `.env`、授权码、API Key、数据库、邮件正文、主题、附件或请求正文。账户用稳定匿名标识关联；原始服务器响应和错误中的私人内容不写入日志。日志从安装支持诊断的版本后开始记录，无法补录旧版本已经发生的问题。还记录解析格式、输入大小、退出信号、静态崩溃分类、异常字段路径、类型及匿名记录和请求编号；原始崩溃输出只在内存中分类，不进入 ZIP。若服务已退出，再次同步会尝试重新连接当前数据目录并继续断点，无需删除缓存或重新添加账户。

## 常见问题与验证边界

- QQ 登录拒绝或 SMTP `535`：分别查看 IMAP / SMTP 结果，核对完整邮箱及登录用户名、网页版协议开关和当前邮箱的有效授权码；账号状态或频率限制也可能导致认证失败。
- AI 失败：检查协议、基础地址、密钥和模型 ID 是否匹配；图片任务需支持视觉输入，原默认 Responses 连接还需 Files API，自定义连接以内联图片提交。已有结果保留，可调整超时或继续未完成任务。
- 升级沿用原数据库。摘要与跟进从清单查看，旧译文作为简体中文缓存复用，历史问答、会话结论和回复预览按来源读取，单文件分析从附件预览查看。旧分类沿用原标签 ID。历史结果保留在本机，来源已从当前缓存移除时，邮件内入口需等来源重新可用。自动整理和翻译 Auto 仍由用户按邮箱开启。
- 资源占用：同步按邮件标识查找已发送副本，避免反复解析整个邮箱；AI 预览最多约每秒更新 10 次，完成后保存完整结果。PDF 页面转换在独立解析进程执行，PPT 继续使用原生渲染组件，逐页释放画布，取消或退出后清理解析进程；切换邮件和收起会话会释放不再查看的附件正文与分析缓存。
- 反馈问题：复现后从“设置 > 开发者”导出诊断 ZIP，并记录步骤与发生时间。旧版没有诊断导出时，记录系统版本、芯片、包内源码标识及错误；隐藏授权码、API Key 和无关邮件内容，勿提交配置 JSON。

已使用既有真实账户检查 IMAP／SMTP 连接、同步、HTML 阅读、附件及分类分页和窗口缩放；DeepSeek 检查覆盖模型目录及固定文本连接测试。自动回归使用合成数据和本机模拟服务，ZIP 理解与服务器草稿并发冲突也在此范围内。当前开发版另在隔离 App 验证了长签名与正文空行定位、草稿重开、写作预设和法语参数，以及旧结果的读取。真实外部发送、其他客户端实际并发编辑、真实邮件 AI 质量、其他服务商、真实大规模邮箱、长期资源开销、最低系统及其他设备仍需专项验证。

开发版已提供可选 IMAP IDLE、新邮件通知、跟进到期通知和角标。它们依赖本机运行、同步结果与系统权限；近期回归使用本机模拟服务，长期 IDLE 和真实通知权限流程仍待专项验证。登录启动、默认邮件 App、本地 EML／mailto 入口及 Gmail／Outlook 专用接入尚未提供。
