# Boxmail 使用指南

本指南适用于 Boxmail 0.1.3（build 38），包含发件人聚合、多账户同步修复和开发者日志导出。从 0.1.0 及更早版本升级时，需重新保存授权码和 API Key，或导入此前导出的配置 JSON；不会自动读取旧钥匙串。安装包中的`版本信息.txt`记录应用版本、构建号、源码标签与完整提交号，可用于核对实际构建内容。

若旧版本在同步后提示“未能读取数据，因为它的格式不正确”，升级到 0.1.3 后直接重开 App，已有邮件和附件继续保留，无需删除账户或清空缓存。少量未下载完成的邮件可点击“继续同步”补拉；若仍报错，请导出新版本的诊断日志。

## 安装与首次配置

发布包内置本机服务、Node.js 和运行依赖，无需另装开发工具、Office 或 LibreOffice。项目声明最低 macOS 14；目前验证环境为 Apple 芯片 Mac，最低系统及 Intel Mac 尚未验证。

1. 解压 ZIP，将 `Boxmail.app` 拖到“应用程序”并打开。
2. 若 macOS 阻止首次打开，确认文件来源后，按“系统设置 > 隐私与安全性”中的“仍要打开”及系统提示操作。当前包使用临时签名，尚未完成 Developer ID 签名和公证。
3. 在“设置 > 账号”添加邮箱地址、登录用户名、IMAP / SMTP 主机、端口、加密方式及授权码，测试连接、保存，再同步。
4. 在“设置 > AI 助手”配置现有连接，或点击“自定义 API”添加服务商，填写协议、API 地址、密钥和模型，测试连接后应用设置。

日常开发构建首次启动会生成演示邮箱和示例邮件；发布包的新安装从空账户开始。演示邮箱不能发送真实邮件。已使用过 Boxmail 的电脑继续读取原数据；需要完全隔离时，可使用新的 macOS 用户。

尚未添加账户时点击“写邮件”会进入账号设置，添加后再创建草稿。

覆盖升级前先用 Command-Q 完全退出 Boxmail，等待退出完成后再替换 App。关闭时会取消后台任务并等待本机服务释放数据目录；启动时可回收同一安装位置、同一数据目录中确认已失去 App 的残留服务。正在使用目录的另一份 Boxmail 仍会阻止启动。

邮箱通过通用 IMAP/SMTP 接入。SSL/TLS 常用端口为 IMAP 993、SMTP 465；STARTTLS 常用端口为 IMAP 143、SMTP 587。切换加密方式时只联动默认端口，自定义端口保留，两种方式均验证服务器证书。旧版 TLS 勾选对应 SSL/TLS，已有账户无需重新添加。

## AI 设置与本机凭证

默认连接保留 DeepSeek 的 `https://api.deepseek.com`、`deepseek-flash` 及 Responses 协议，自定义提示词继续使用，旧钥匙串密钥需重新保存或通过配置 JSON 导入。BYOK 指使用自己的 API 密钥；可保存最多 20 个服务商，从“当前服务商”切换，所有邮件 AI 功能共用所选连接。

点击“自定义 API”，填写唯一的 Provider ID、显示名称、API 地址和协议，然后添加所需模型。Provider ID 以小写字母开头，只用小写字母、数字和连字符，创建后保持不变；每个服务商在本机 `.env` 中使用独立凭证。API 地址填基础路径，远程使用 HTTPS，本机回环地址允许 HTTP。

| API 协议 | 基础地址与能力 |
| --- | --- |
| OpenAI Responses | 按服务商填写基础路径，自动请求 `/responses`；图片及 PDF / PPT 理解需视觉输入，原默认连接还需 Files API，自定义连接内联提交图片。原默认连接保留 Low / High / Max，其他模型按声明选择推理等级 |
| OpenAI Chat Completions | 例如 `https://gateway.example/v1`，自动请求 `/chat/completions`；图片以内联方式提交，模型需支持视觉输入 |
| Anthropic Messages | 例如 `https://api.anthropic.com`，自动处理 `/v1/messages`，地址已含 `/v1` 时不重复添加；图片以内联方式提交 |

“获取模型”会展示候选模型，勾选后加入目录，已有模型的名称和参数会保留。列表按服务商、协议和基础地址分别缓存，失败保留上次成功结果。可通过“添加模型”维护目录，也可从“模型设置”直接输入目录外的模型 ID。超时可设为 10 至 600 秒，服务商需支持所选协议的流式返回。

展开模型行可填写显示名称、上下文窗口和最大输出 token 数，选择文本、图片输入能力，以及启用推理等级。容量支持 `256K`、`32K`、`1.5M` 等写法，1K = 1000；最大输出数不能超过上下文窗口。留空使用默认能力，明确填写输出数会限制单次请求。新自定义模型默认仅支持文本，图片、PDF 和 PPT 理解需按服务商说明勾选图片。

启用推理后，可增删等级并填写它在接口中的实际发送值，例如 High 对应 `high` 或 `max`；Off 留空表示不发送推理参数。模型选择菜单只显示该模型声明的等级。Anthropic 可选择思考预算或自适应推理，须与具体模型能力一致；预算模式按等级分配思考 token，自适应模式使用等级映射。Chat Completions 可按服务商要求选择 `max_completion_tokens` 或 `max_tokens` 作为输出上限字段。

连接、目录、密钥和当前选择需点击“应用”或“确定”保存，取消保留原设置；成功获取的模型列表缓存独立保留。移除服务商后应用设置会移除其凭证，至少保留一个连接。“测试连接”会实际调用所填服务，可能产生服务商费用。

总结、回复、写信、分类、附件理解和翻译均有可编辑的默认提示词，清空保存会恢复默认。升级只替换与旧默认值相同的内容，保留自定义提示词、个人签名和已有结果；已有结果需重新生成才应用新要求。

邮箱授权码和 API Key 保存在当前数据目录的 `.env`，默认路径为 `~/Library/Application Support/Boxmail/.env`。在设置界面保存账户或应用 API Key 后自动写入，权限为仅当前用户读写（`0600`）。文件为明文，可从“设置 > 高级 > 本机数据 > 显示凭证文件”定位；不要提交到 Git 或分享。服务器地址、模型、提示词和偏好仍保存在 SQLite。

手工编辑时使用 UTF-8，每行一个 `KEY=VALUE`，键名区分大小写并保留 ID 中的连字符。默认 AI 密钥为 `BOXMAIL_AI_KEY`，自定义服务商为 `BOXMAIL_AI_PROVIDER_<Provider ID>_KEY`，邮箱授权码为 `BOXMAIL_MAIL_<账号 ID>_PASSWORD`；账号 ID 可在导出的配置中查看。值可使用单引号包围以保留原文，或使用双引号及 JSON 转义，例如 `\n`、`\"`、`\\`。`#` 是引号外的注释起点，不执行变量替换或 shell 命令；不要在 shell 中 source 此文件。配置导入生成 `BOXMAIL_CONFIGURATION_<UUID>` 条目，保留生成的键名并修改值即可，SQLite 保存对应引用。

每次同步、发信和 AI 请求都会读取当前文件，手工修改后无需重启。后台同步也可在启动后直接读取，不需要系统授权；邮箱授权码缺失或文件无法读取时，侧栏显示“检查邮箱凭证”，可进入账号设置处理。普通偏好保存不会清空未修改的密钥。

升级不会自动访问或删除旧钥匙串。请在“设置 > 账号”重新填写授权码并保存，在“设置 > AI 助手”为各服务商重新填写 API Key 并应用；也可导入此前导出的配置 JSON。开发启动可通过绝对路径 `BOXMAIL_ENV_FILE` 指定其他 `.env` 文件，界面会显示实际路径。

## 阅读、同步与写信

每次同步先核对服务器邮件数量与 UID 清单，每次最多读取 200 封的轻量元数据。服务器漏返回部分邮件时，自动缩小批次补拉缺项；清单完整后才校准本机缓存，补拉后仍不完整则保留原缓存并提示重试。 多账户同步最多同时运行两个账户，其余排队。单次会话在批次间复用已校验的清单；每批核对数量、文件夹身份与下一封 UID（UIDNEXT），发生变化时重新读取；服务器未提供 UIDNEXT 时，清单最多复用一分钟。新的同步会话也重新核对。

各文件夹每批最多下载 200 封缺失或需修复的正文，并在约 20 秒预算后让出；后台会自动轮转未完成的文件夹，直到本次范围内的历史邮件全部补齐，无需每批手动继续。列表底部持续显示已下载与服务器总数，正常同步及批次结束不弹窗。顶部同步按钮在运行时提供“停止本次同步”，已下载邮件保留，下次同步会自动继续。超过 1 MB 的邮件优先分段下载；服务器忽略分段、返回错位数据或报告大小不一致时，自动重试并回退完整原文。已完成的邮件逐封保存，后续同步继续补齐。一处文件夹失败后会继续处理其他文件夹，错误在对应列表显示。列表每页 100 封，“显示更多邮件”位于滚动列表末尾；失败或停止后，可从底部状态栏重新发起同步。网络恢复和电脑唤醒时会尝试同步；退出、睡眠或离线期间不会持续收信。邮件状态未变化时不重复写入，也不重新生成搜索索引。

清单阶段显示已读取与服务器总数，正文阶段显示已下载与总数。邮件解析以及 PDF、Word、Excel、PPT 附件提取在独立解析进程运行，支持超时与取消。单个解析进程崩溃或超过内存预算时，原附件仍保留，继续处理其余邮件；未完成解析的正文会延后重试。一个账户启动超时不会阻断其他账户的进度查询；查询连续失败三次后，应用请求停止本次同步并退出忙碌状态，保留已下载邮件。后端连续 120 秒没有阶段或进度更新时也会中断任务，可检查网络后重试。

若网页版能看到历史邮件、Boxmail 却没有，请先检查服务商的收取范围。网易邮箱在“设置 > POP3/SMTP/IMAP”中将“仅收取最近 30 天”改为“收取全部邮件”并保存，再同步。旧的已发送邮件也受此设置影响；客户端只能同步服务器当前开放的邮件。QQ 邮箱也可在网页版“设置 > 账户 > 收取选项”检查范围。[网易官方帮助](https://help.mail.126.com/searchFAQ.do?m=search&word=%E6%94%B6%E4%B8%8D%E5%88%B0%E9%82%AE%E4%BB%B6)

HTML 邮件支持表格、CID 内嵌图片和外部图片。默认屏蔽远程图片，可点击“加载本封邮件图片”或在阅读设置中调整；邮件脚本、表单和嵌入页面会移除，链接通过默认浏览器打开。

会话按同账户的 Message-ID、In-Reply-To 和 References 建立时间线，不按相同主题直接合并，也不跨账户合并。当前选中的邮件固定在最上方，其余往来按时间倒序显示，较新的邮件在前；选择旧邮件时也会将其置顶。回复发送成功后，本机副本即可关联原会话，无需等待服务器同步。每次载入 100 封，正文与附件按需读取，引用可展开。顶部操作针对当前选中的邮件，其他往来可逐封回复或打开；会话只包含已缓存历史，尚不提供整段会话 AI。

邮件列表、草稿列表和会话折叠项的缩略预览共用签名过滤规则，排除可识别的签名分隔段、HTML 签名区和移动设备落款，保留历史引用。草稿箱及关联回复草稿只有签名或正文为空时，显示“尚未撰写正文”。已有缓存刷新后即可生效，无需重新同步；完整正文、签名和引用仍保留。搜索范围继续包含原文，若关键词只出现在被过滤的签名中，结果仍会列出该邮件，缩略改用不含签名的预览。

展开邮件收件人与抄送后，长名单在限定高度内独立滚动，内容溢出时持续显示细滚动条。HTML 正文和转发原文中的长收件人名单同样保留独立滚动条；“收件人／抄送／密送”标题保持横排并与名单顶部对齐。滚动条仅用于本机展示，不改变原邮件或转发快照。

从附件中心、附件预览或智能整理打开原邮件时，会切换到对应账户与文件夹，自动滚动并高亮目标邮件，阅读区同时显示同一封原文。较旧邮件不在首批列表中时，会先显示目标行；重复打开同一封邮件也会重新定位。

### 列表、多选与快捷键

邮件列表默认按发件人聚合，同一账户内的实际发件邮箱忽略大小写后归为一组；同名但不同邮箱、不同账户以及缺少发件邮箱的邮件各自保留。每组显示最新邮件及匹配邮件总数，按最新邮件时间倒序排列；展开后，较早邮件也按时间倒序显示，超过一页可点击“显示更早邮件”。搜索和筛选同时作用于组计数及组内邮件。

点击发件人左侧箭头展开或折叠，点击邮件行阅读正文；列表标题右侧的“发件人”菜单可切换为“逐封显示”，选择会保留到下次启动。选中聚合行时，右方向键展开、左方向键折叠。从附件或摘要打开较早邮件时会自动展开并定位。草稿搜索继续逐封显示。

全选和批量操作仅包含当前显示的邮件，折叠组内未显示的邮件不会被一并选中。折叠正在选择的旧邮件时，选择会回到该组最新邮件；若还选有其他组的邮件，则保留其他选择。

单封回复、转发及邮件 AI 快捷键仅作用于正在阅读的一封普通邮件。多选、草稿搜索结果、设置或写信窗口中会禁用这些命令；已有写信窗口时，新建命令也会禁用，避免替换当前草稿。

邮件行采用一行预览，将附件、星标及已有总结状态放在主题旁，分类显示在预览右侧。预览优先显示可读文字，省略混在文字中的裸链接；只有链接的邮件仍保留链接。正文、搜索索引与发送内容不受影响。账户名称与邮箱地址相同时，侧栏改用服务商或域名作为名称，完整地址可悬停或在账户菜单查看。

在邮件列表中，按住 Shift 选择连续范围，按住 Command 点击可离散多选；标题旁的选择按钮或 Command-A 仅全选当前已加载的邮件，不会自动选中未加载的历史。多选后，列表上方显示批量归档、移到已删除、标记和分类操作；右键菜单也作用于所选邮件。每批最多 1000 封，草稿搜索结果不参与邮件批量操作。

| 按键 | 操作与范围 |
| --- | --- |
| 上／下方向键 | 列表聚焦时切换邮件；配合 Shift 连续选择 |
| Command-A | 列表聚焦时全选已加载邮件 |
| Control-Command-A | 列表聚焦时归档所选邮件 |
| Delete | 列表聚焦时将所选邮件移到已删除 |
| Command-Shift-U | 列表聚焦时切换所选邮件的已读状态 |
| Command-Z | 撤销当前会话最近一次手动邮件操作；文字编辑时沿用编辑器的撤销 |
| Escape | 列表聚焦且多选时取消选择 |
| Command-F | 聚焦顶部邮件搜索框 |
| Command-N / Command-R | 写邮件／回复 |
| Command-Shift-F / Command-Shift-R | 转发／同步所有账户 |

批量操作在本机事务中整体提交，任一邮件不存在、状态冲突，或需要修改服务器状态的账户正在同步时，不会只完成其中一部分。操作后底部显示结果和“撤销”；撤销只还原本次改动的字段，保留其他编辑。撤销记录只在当前会话保存，重启后不保留；相关状态被后续操作改变或邮件已同步为新的身份时，撤销会拒绝覆盖，可从已删除或已归档中恢复。自动标记已读不覆盖手动操作的撤销记录，永久清空已删除邮件不支持撤销。

邮件列表底部显示上次同步时间；旁边的信息按钮展开本机缓存量、上次服务器数量与搜索范围说明。自动补齐期间隐藏手动继续入口；同步失败、无进展或停止后，保留重试与继续入口。单封正文持续不返回时，先继续下载同一文件夹的其他历史邮件，健康邮件补齐后自动再补拉一次；仍失败的邮件保留为待下载，不保存残缺正文。连续三封正文失败时暂停该文件夹，继续处理其他文件夹，避免服务器不可用时不断重连。剩余数量和错误留在列表中，下次同步重试缺失邮件。

### 写信与草稿

点击侧栏“写邮件”或按 `Command + N` 新建本机草稿。To / Cc / Bcc 输入姓名或邮箱关键词后显示当前账户历史邮件和草稿中的联系人，支持上下键选择、Enter 或 Tab 填入、Esc 关闭；跨字段去重，只替换当前地址片段。空输入、无匹配或中文输入法组合期间保持正常编辑。联系人填入后写作 `姓名 <邮箱>`，多个地址可用逗号、分号或换行分隔。

回复全部会处理 Reply-To、原 To / Cc、去重和自身地址排除，转发沿用独立的引用语义。短正文的个人签名位于编辑区底部，长正文时跟随文末；视觉留白不写入邮件，已移除的签名不会自动补回。

HTML 邮件转发时，编辑区上方可填写转发说明，下方“转发原文”保留原邮件的表格、字体、配色、链接与图片布局；原文作为独立快照保存，编辑说明或插入 AI 草稿不会改写原邮件。发送同时包含 HTML 和纯文本，内嵌图片转换为邮件内的 CID 图片；预览中的外部图片继续遵循阅读设置，默认按需加载。旧转发草稿的引用内容完整且未修改时，会恢复为排版原文；已编辑的旧引用继续保留原文字，避免覆盖修改。纯文本邮件仍使用原有转发方式。

转发发送时为附件保存独立副本，原邮件和已发送邮件均可查看、预览和理解附件，删除其中一封不会影响另一封。旧版共享附件会在对应文件夹同步时修复。

正文支持 `Command + V` 粘贴 Finder 文件和剪贴板图片，附件栏也可选择文件；普通文字仍粘贴到正文，文件夹不能作为附件，单附件限制 25 MB。草稿在本机保存，尚未同步服务器草稿。

发送前需确认。若显示结果不确定，先检查服务商已发送文件夹及收件情况，再决定后续处理；应用不会自动重发。同一草稿同时只会实际投递一次；发送前失败会保留为可编辑草稿。SMTP 接受后归档失败也可能显示提示，不能据此再次发送。草稿发送期间不能移除所属账户；移除账户会清理该账户的本机缓存及待关联邮件附件，保留其他账户仍引用的附件和服务器邮件。

### 恢复、归档与计数

“已删除”中的恢复和“已归档”中的取消归档会回到操作前的文件夹，按钮及右键菜单显示目标。归档后删除再恢复，仍可继续取消归档。旧记录缺少来源时优先识别服务器路径，再按发件地址区分已发送，其余返回收件箱；来源丢失时无法准确还原。

“已删除”右上角的“清空”在确认后永久删除当前账户整个服务器已删除文件夹，包括未下载或未显示的邮件，不受搜索与筛选限制，也不可撤销。其他账户、文件夹及仍被引用的附件保留。清空期间保存的账户名称、签名和连接设置继续保留。

侧栏邮箱项在数量大于 0 时显示计数（为 0 时隐藏），其中已发送数和同步详情中的缓存数按当前账户、当前文件夹实时计算，不受搜索与筛选影响；服务器数单独显示为上次同步快照。“设置 > 高级 > 本机数据”可核对全部账户和文件夹明细，附件数包含本机草稿引用的文件。

删除草稿会清理不再被其他邮件、草稿或保留记录引用的附件。发送成功后，原文和附件由已发送邮件持有，隐藏的草稿仅作为发送回执。

## 邮件 AI 与分类

| 功能 | 入口与操作 |
| --- | --- |
| 总结 | 邮件上方直接点击“AI 总结”；查看已有总结或生成新总结，可复制或重新生成 |
| 翻译 | 邮件上方“翻译”或 `Command + Shift + T`；保留原排版逐段显示，可从同一按钮切回原文 |
| 回复 | 邮件上方“AI 回复”；选择感兴趣、不感兴趣、感谢或填写自定义要求，先生成预览 |
| 附件理解 | 正文下方附件区的“理解本封邮件附件”；批量理解本封附件，也可在预览中单独处理 |
| 写信 | 写信窗口中按要求生成正文，再审核编辑 |
| 智能整理 | 侧栏“智能整理”；选择范围、分析、审核分类建议，确认后应用，可撤销 |

“摘要集合 > 总结未读邮件”每次最多处理 10 封未总结的未读收件邮件，每封单独调用模型并使用自己的超时设置。任务在本机后台运行，界面显示进度；一封失败后继续下一封，成功结果立即保存。再次点击只处理仍未总结的邮件，退出应用会中断未完成任务，已有结果保留。单封内容过长或服务商繁忙仍可能触发模型超时，可稍后单独重试。

回复预览支持复制、关闭和重新生成；点击“使用内容”才创建草稿，再次使用同一预览会保留原草稿的编辑。三种态度不代为承诺参会、采购或交付。AI 写作只生成正文，不附签名或占位符；翻译忠实保留原文。

总结默认保留核心事实、期限及必要待办，下一步建议最多 4 项。起草建议衔接待审核回复，附件建议定位到本封附件区，线下事项只显示提醒；生成总结不会自动执行建议。已有总结与关键信息仍可完整复制。

智能整理应用后的撤销会检查分类是否仍与应用时一致；若已手动修改分类，会保留现状并提示无法撤销本次整理。

侧栏“摘要集合”按当前账户显示已收录摘要。每项可“从列表移除”，也可点击“多选”后移除选中项，或用“清空列表”移除当前账户的全部列表项；这些操作只整理列表，邮件内的总结、待办、原文和搜索结果保留，不会修改服务器邮件。操作后可立即撤销，也可在“已移除”中逐项或多选恢复，重启后收录状态继续保留。重新生成邮件总结会将新结果重新收录到列表；单纯打开邮件不会恢复已移除项。

附件批量理解按本封邮件的顺序处理，已有结果默认复用，单项失败不阻止后续文件。支持只重试失败项、暂停后继续或明确重新理解全部；成功结果立即保存，重启后未完成任务可继续，失败不会覆盖已有分析。每次请求独立使用超时设置。

智能整理可选未分类或全部收件邮件，以及最近 10、50、100、200 封，每批最多 6 封。暂停、部分失败或重启后可继续未完成项，也可确认已有建议；已有建议待确认时先完成审阅。分类只修改本机标签，不移动服务器邮件。

“智能整理 > 管理分类”可维护所有账户共用的名称和说明，手动标记与 AI 使用同一目录。最多 100 类，名称 1 至 32 字符且不重复，说明最多 500 字符；“未分类”不可删除。改名同步更新标签，删除分类保留邮件并归为未分类；修改需等待相关任务完成。

总结、回复预览、写信、附件理解（含批量）和分类整理会随着模型输出逐步显示内容，可继续阅读其他邮件；返回前的附件读取和模型准备阶段显示处理状态。输出流断开后自动重连，恢复当前任务的显示。若服务商只在最后返回完整答案，中间仍需等待服务商输出。

翻译保留原邮件的段落、链接、按钮、表格、图片、配色及代码块，在对应位置替换文字；命令和链接地址保持原样。可随时切回原文，译文完成后保存在本机，重新打开后仍可查看。旧版 HTML 邮件的纯文本译文首次查看时会重新翻译，以恢复原有排版。

任务所需邮件、附件文本或图片会发送到配置的 AI 服务商；翻译仅提交主题和可翻译文字。生成中的文字是预览，应用只保存完整有效的结果，错误显示在对应位置；失败时保留原文和已有结果。云端时长和模型兼容性取决于服务商及输入内容。

## 附件预览与理解范围

附件默认打开“原文件预览”，可切换“AI 理解”。PDF 使用 PDFKit，Word 使用系统 Quick Look 生成的文档及本地图片，单栏居中；PPT / PPTX 和其他系统支持格式沿用 Quick Look。XLSX 在本机显示尺寸、合并、字体、边框、颜色和内嵌图片，不执行公式。原文件字节保持不变，不使用在线预览服务。

Word 的特殊样式和分页取决于系统预览；XLSX 最多展示前 10 个工作表、各表 400 行和 60 列，复杂图表、条件格式及打印分页请用“打开原文件”核对。

| 理解方式 | 范围与限制 |
| --- | --- |
| DOCX、XLSX、TXT、CSV 等文本 | 提取文本最多保存 200,000 字符，单附件 AI 分析最多提交 60,000 字符，截取会标明 |
| JPEG、PNG、GIF、WebP | Responses 通过 Files API 上传；Chat Completions 和 Anthropic 内联提交，均需支持视觉输入的模型 |
| PDF，包括扫描件 | 本机转逐页图片，最多 20 页、页面图片合计 25 MB，超限需拆分 |
| PPT / PPTX，兼容 PPS / PPSX | 本机渲染后复用 PDF 流程，限制相同；PPTX 隐藏页也处理，旧 PPT 使用系统预览可见页 |

渲染不保留动画和视频，特殊字体或复杂版式可先导出 PDF。损坏、加密、取消或超限会显示提示并保留已有结果。图片上传设置一小时有效期，任务完成或失败后尝试删除云端临时文件，本机附件与分析继续保留。

类型配色为 PDF 红、表格绿、Word 蓝、PPT 金、图片紫、其他灰；图标识别旧格式不代表该格式都支持 AI 文本提取。附件中心可搜索、预览和下载，并返回所属邮件。

## 搜索

顶部搜索框支持关键词、英文双引号短语及组合条件，也可打开旁边的条件面板。正文、往来地址、主题、分类、附件名称和提取内容、译文及 AI 结果均可检索；中文支持两字词及句中子串。

| 条件 | 示例与语义 |
| --- | --- |
| 发件人 | `from:wang@example.com`，匹配姓名或邮箱 |
| 收件人 | `to:finance@example.com`，同时检查 To / Cc / Bcc |
| 抄送、主题、分类 | `cc:team subject:合同 category:审批` |
| 日期 | `after:2026-10-01 before:2026-11-01`，起始日包含、截止日不包含 |
| 状态 | `is:unread`、`is:read`、`is:starred` |
| 附件 | `has:attachment` |
| 账户 | `account:me@example.com`，支持完整邮箱、唯一名称或 ID |
| 文件夹 | `folder:sent`，支持 inbox、sent、archive、trash、drafts、spam 及中文名称 |

多个条件按同时满足组合，例如 `"采购合同" from:"王敏" folder:inbox`。明确的账户条件优先于侧栏选择；无效日期、未知条件、引号未闭合或账户歧义会显示错误。

条件面板的日期日历支持翻月、年月菜单、今天与清除，按本机时区处理，选择后保留其他条件。状态菜单中的已发送、草稿箱、已归档、已删除与文件夹同步；未读、已读、星标可叠加文件夹。

明确选择草稿箱时搜索本机未发送草稿，日期取最后更新时间，可继续编辑原草稿；已发送记录和服务器草稿不计入。普通邮件索引数量不包含这些草稿。

搜索和会话只覆盖本机已缓存内容，未下载历史需继续同步。“设置 > 高级 > 本机搜索索引”可检查并重建派生索引。索引更新或重建失败时，保留原索引和待更新记录，可再次重试，不影响邮件原文及附件。

## 数据保存与迁移

默认目录为 `~/Library/Application Support/Boxmail/`：`boxmail.sqlite` 保存邮件、草稿、设置、模型列表及 AI 结果，`attachments/` 保存附件。缓存和备份未加密，凭证单独保存在同目录的 `.env`（或 `BOXMAIL_ENV_FILE` 指定文件）。

| 方式 | 入口与用途 | 是否包含密钥 |
| --- | --- | --- |
| 配置 JSON | 设置 > 高级 > 配置导出与导入；迁移账号、AI、提示词、签名和偏好 | 包含已保存的授权码和 API Key，未加密 |
| 完整 ZIP | 设置 > 高级 > 完整备份与恢复；保存数据库、附件及校验清单 | 不包含 `.env` 凭证 |
| 更改位置 | 设置 > 高级 > 本机数据；下次启动迁移整个本机数据目录 | 包含数据目录下的 `.env`；外部指定文件不移动 |

### 配置导出与导入

配置操作需要本机服务启动成功。若按钮不可用并提示数据目录占用，先关闭设置，在主窗口重试启动；不要删除数据目录中的锁文件或数据库。旧版残留进程无法自动识别时，在“活动监视器”中退出对应的 Boxmail 本机服务，或重启 Mac 后再打开 App。

先应用设置，再点击“导出配置…”选择 JSON 保存位置。导出包含所有已配置服务商，即使当前未选中或 AI 已关闭；只从本机 `.env` 读取已保存的真实邮箱账号及这些服务商的凭证。仅保留自定义服务商时，不读取旧默认连接的密钥。取消或读取失败不会替换目标文件；文件以仅当前用户读写的权限保存，包含明文密钥，请妥善保管。

选择 JSON 后先检查账号新增、更新数量、当前 AI 选择，以及每个服务商的地址、协议、模型数量和是否包含密钥，再确认导入；预览不展示密钥内容。邮箱地址忽略大小写后合并，已有账号 ID、同步历史和邮件保留，新邮箱新增，其他账号及邮件、附件、草稿保留。AI、签名和偏好按文件替换，文件中为空的服务商密钥也按空值应用。

导入不读取旧凭证；校验、写入或冲突失败保留原配置，并清理本次写入的临时凭证。成功提交后即采用新设置，即使列表刷新失败，后续“应用”也保留导入内容。若提交响应丢失，会再次检查生效状态；暂时无法确认时保留可能正在使用的凭证，按提示重新打开 App 后检查。预览期间配置改变时需重新选择文件；已有多个同邮箱账号时先整理账号。

支持格式版本 1 和 2、最多 100 个账号及 2 MB JSON。含 BYOK 服务商的配置使用版本 2，包含独立密钥、模型 ID 与显示名称、上下文窗口、输出上限、输入类型、推理映射和协议兼容参数，并保留当前服务商、模型、超时及开关。旧版单连接配置仍可导入。文件不包含邮件、附件、草稿、AI 结果、活动、独立模型缓存和本机数据位置；完整迁移可分别使用配置 JSON 和完整 ZIP。

### 完整备份与恢复

ZIP 包含一致性 SQLite 快照、登记的附件，以及数量、字节数和逐文件 SHA-256 清单。恢复前先校验文件和关联，展示摘要并确认；最终恢复还会核对文件是否变化。同步、发送或 AI 任务期间不能恢复，维护期间拒绝并发写入。

邮件内的总结和待办、摘要列表的收录或移除状态、原排版译文、多服务商及模型参数均随完整备份保存；恢复不会把已移除摘要自动重新收录。恢复后清除此前的预览缓存、列表撤销和多选状态，再从备份数据读取结果，恢复前发出的旧请求不会覆盖恢复后的数据。

恢复前自动生成 `backups/before-restore-*.zip`，失败则停止。恢复失败回滚并保留原数据；成功后重建索引，中断的发送转为待确认，整理和附件任务转为暂停，单封 AI 任务标为失败。核对账户和待同步更改后再同步服务器。

ZIP 不含 `.env`，恢复也不修改当前凭证文件或数据位置。跨电脑恢复后请另行导入配置 JSON 或恢复凭证文件；旧备份中的凭证引用若在当前文件中不存在，也需重新填写或导入配置。压缩文件上限 512 MB、解压内容 2 GB、数据库 256 MB、单附件 50 MB；登记附件缺失时拒绝生成残缺备份。更大数据集可退出 App 后复制整个数据目录及 SQLite 关联文件，凭证另行管理。

### 更改数据位置

选择本机或已挂载本地磁盘的空文件夹，应用设置后重启。启动时复制一致性数据库、附件、数据目录下的 `.env` 和已有备份，更新附件路径，确认后切换，原目录保留。非空、互相包含、空间不足或文件缺失时停止迁移，继续原位置。

外置磁盘缺失时显示重试入口，接回后继续使用，不会新建空邮箱。开发环境变量 `BOXMAIL_DATA` 可覆盖本次启动位置，不执行已保存的迁移计划，也不改写日常设置。`BOXMAIL_ENV_FILE` 指定的外部凭证文件不随数据目录迁移。

## 开发者日志

打开“设置 > 开发者 > 导出诊断日志…”，选择保存位置，生成 ZIP。同步正在运行、本机服务未连接或请求超时时，仍可导出已经保存的日志；导出无需等待同步结束。复现问题后尽快导出，并同时记录操作步骤与大致发生时间，方便关联记录。

日志自动记录同步排队、连接、清单、下载、解析、完成、失败或取消等关键事件，以及本机 API、模型请求的错误类型、状态码和耗时。后端每 30 秒记录进程内存、CPU 时间及事件循环延迟，帮助判断资源占用。文件保存在当前数据目录的 `logs/`，应用与后端各保留当前文件及两份轮转文件，每份约 1 MB；较早记录会被覆盖。

ZIP 只包含这些日志、版本和系统信息、匿名化同步状态与说明文件，不包含 `.env`、授权码、API Key、数据库、邮件正文、主题、附件或请求正文。账户用稳定匿名标识关联；原始服务器响应和错误中的私人内容不写入日志。日志从安装支持诊断的版本后开始记录，无法补录旧版本已经发生的问题。还记录解析格式、输入大小、退出信号、静态崩溃分类及数据解码的结构字段；原始崩溃输出只在内存中分类，不进入 ZIP。若服务已退出，再次同步会尝试重新连接当前数据目录并继续断点，无需删除缓存或重新添加账户。

## 常见问题与验证边界

- QQ 登录拒绝或 SMTP `535`：分别查看 IMAP / SMTP 结果，核对完整邮箱及登录用户名、网页版协议开关和当前邮箱的有效授权码；账号状态或频率限制也可能导致认证失败。
- AI 失败：检查协议、基础地址、密钥和模型 ID 是否匹配；图片任务需支持视觉输入，原默认 Responses 连接还需 Files API，自定义连接以内联图片提交。已有结果保留，可调整超时或继续未完成任务。
- 升级：现有邮件、附件和草稿保留，旧默认 AI 参数及提示词自动迁移；自定义值保留，不会自动重写已有内容。
- 资源占用：同步按邮件标识查找已发送副本，避免反复解析整个邮箱；AI 预览最多约每秒更新 10 次，完成后保存完整结果。PDF 页面转换在独立解析进程执行，PPT 继续使用原生渲染组件，逐页释放画布，取消或退出后清理解析进程；切换邮件和收起会话会释放不再查看的附件正文与分析缓存。
- 反馈问题：复现后从“设置 > 开发者”导出诊断 ZIP，并记录步骤与发生时间。旧版没有诊断导出时，记录系统版本、芯片、包内源码标识及错误；隐藏授权码、API Key 和无关邮件内容，勿提交配置 JSON。

已有验证包括 QQ 的 SSL/TLS 认证、同步与 HTML 阅读，以及使用虚构邮件的 DeepSeek 流程。真实外部发送、其他服务商、大规模邮箱、最低系统和其他设备仍需专项验证。IMAP IDLE、服务器草稿、系统通知、登录启动及 Gmail / Outlook 专用接入尚未提供。
