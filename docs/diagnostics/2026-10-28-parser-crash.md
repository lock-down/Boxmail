# build 35 同步期间后端异常退出

本文保留 0.1.1 build 35 测试机故障的历史证据。当前 0.1.4（build 42）进一步覆盖 Excel 预览、完整 PPT 转换与页面解析的进程隔离，并为永久无效 MIME 保留原始 EML；当前行为与完整验证范围见 [开发说明](../DEVELOPMENT.md) 和 [变更记录](../../CHANGELOG.md)。

## 日志证据

依据测试机提供的诊断导出，版本为 0.1.1 build 35，Apple 芯片，macOS 27.0.1。以下时间已由日志的 UTC 转为北京时间，发生日期为 2026 年 10 月 27 日。

| 时间 | 事件与含义 |
| --- | --- |
| 17:02:45 | 本机服务连接成功；此前短暂的 `/health` 连接失败属于启动探测。 |
| 17:02:54 | 六个账户发起同步，两个并行，其余排队。 |
| 17:02:56 至 17:02:59 | 两个账户完成，后续账户开始；说明队列和进度轮询在故障前正常工作。 |
| 17:03:03 | 客户端记录 `service.exited`，`status=signal`、`code=6`，即后端被 SIGABRT 终止。 |
| 17:03:03 起 | `/sync-status` 返回 NSURLErrorDomain `-1004`，停止请求和模型目录随后也无法连接。它们是后端退出后的结果，并非最初的请求超时。 |
| 17:03:42 | 导出时仍有附件阶段的旧快照，显示 94 / 2493 封；清单已完整取得。导出错误地继续标记 `connected=true`，运行及排队状态也未反映后端已经退出。 |

原始导出没有附件格式、崩溃栈或原生内存峰值，不能唯一确定是哪份附件或哪个底层库触发 SIGABRT。普通 PDF 并发样例在本机未复现同一原始崩溃，不将测试注入的故障当作触发文件的证据。

## 修复边界

原实现将 MIME、Word、Excel 和 PDF 解析放入同一 Node 后端内的工作线程；原生崩溃和进程级内存耗尽仍可能终止 HTTP 与 SQLite 服务。Node 官方也说明线程的资源限制只约束 JS 引擎，外部缓冲区不在这些限制内，进程仍可能因全局内存耗尽而中止。[Node.js 24 工作线程说明](https://nodejs.org/docs/latest-v24.x/api/worker_threads.html#new-workerfilename-options)

build 36 使用独立解析子进程和独立进程组。MIME 及同步中的 PDF、Word、Excel、PPT 文本处理不在 HTTP 进程中执行；PDF 图像解析也在子进程内完成。每个解析任务保留 60 秒期限，子进程 V8 old-space 预算为 192 MB，独立守护逻辑每 100 毫秒检查 RSS，默认超过 512 MB 时终止该解析进程组。原生画布和图像缓冲区也计入 RSS。两账户的并发上限继续保留。

附件解析失败时，邮件与原附件仍可提交保存，提取文本标记失败，其余邮件继续同步。MIME 解析失败时，当前邮件标识进入会话内延后集合，继续处理其他邮件；有限补拉仍失败则保留断点，下一次同步重试，不把残缺正文写为完成。

解析进程不继承邮箱令牌、凭证路径、API 环境密钥或 Node 预加载参数。取消、超时或服务退出会终止它及其拥有的渲染进程，并清理独立临时目录；即使解析主循环被阻塞，守护逻辑仍可响应所有者失联。

诊断新增解析格式、输入大小、耗时、退出信号和静态原因分类。后端标准错误会在内存中有限保留并分类，不将原始 stderr、文件名、邮件内容或密钥写入日志。客户端识别后端退出后清除旧的运行状态，保留最后阶段和已下载计数；再次同步会重新连接当前数据目录，待重启迁移计划不受影响。

## 验证范围

- 用真实 SIGABRT 注入 PDF 与 MIME 解析子进程，验证 HTTP 服务存活、另一账户完成、原附件保留，以及 MIME 断点重试。
- 用原生 Buffer 分配和阻塞循环验证 RSS 保护，覆盖 JS 堆限制之外的内存。
- 验证取消会回收解析进程及其子进程；后端所有者被终止后，阻塞的解析进程也会结束并清理临时目录。
- 回归实际 PDF 文本、页面图像、PPT / PPTX 页面、事务提交、同步和诊断导出。
- 验证客户端标准错误分类及目录锁释放，退出后的快照保留附件阶段与已下载计数。

在隔离 App 中终止本机模拟账户的后端后，界面显示具体退出信号并结束同步；点击“重试同步”建立了新的后端进程，日志记录重新连接成功。

测试使用合成文件、模拟邮箱和本机服务。上述故障注入证明新的隔离与恢复边界，不能替代测试机原附件的最终复测。
