# 0.0.14：写信与附件体验修复

发布日期：2026-10-22。App 与本机后端统一为 **0.0.14**，构建号 **15**，本地 Git 标签为 `v0.0.14`。日常开发 App 与 Release ZIP 同步更新；包内 `版本信息.txt` 记录发布标签、完整源码提交号和生成时间。文档入口见 [文档索引](README.md)。

## 功能变化

- 联系人建议仅在当前地址片段包含关键词时显示匹配项，空输入、纯空格、无匹配及逗号后的空片段不弹出列表。姓名与邮箱单行排列，移除首字头像、标题和提示区；独立非激活浮层保持顶部、输入行和正文位置稳定，支持键盘、鼠标选择及跨字段去重。
- 收件人、抄送、密送恢复与主题一致的蓝色聚焦下划线，中文输入法组合期间保留正常输入与确认行为。
- 短正文的签名放在编辑区底部，长正文时自然跟随文末，继续可编辑。视觉留白不写入正文；插入 AI 草稿保留原有签名，用户已移除的签名不自动补回。
- Word 原文件预览使用系统 Quick Look 生成的文档及本地图片，单栏居中展示，保留表格和内容样式；滚动区采用透明轨道、无边框细滑块。未生成 HTML 时保留原生预览，PDF、表格及其他类型沿用原有路径。
- 在正文按 Command-V 可添加 Finder 文件和剪贴板 PNG、TIFF 图片，TIFF 转为 PNG。附件栏保留“添加附件”入口；普通文字继续粘贴到正文，选择与粘贴共用单附件 25 MB 限制，文件夹显示具体错误，导入完成后保存草稿。

## 数据与兼容性

沿用 SQLite `user_version=2`，保留已有账号、邮件、草稿、附件、自定义提示词、模型缓存及待同步操作；后端接口和记录字段保持兼容。预览和粘贴均在本机处理，原文件字节保持不变。联系人仅来自当前账户的本机历史邮件和草稿，不增加云通讯录接入。

Word 的特殊样式和分页仍取决于系统预览能力；需要核对原始分页时使用“打开原文件”。发送确认、AI 内容审核及其他既有功能范围保持原有行为，见 [项目说明](../README.md)。

## 验收

重新执行 `./script/test.sh`，通过 **133 项后端测试、48 项 Swift 测试**，后端无跳过。新增签名测试覆盖完整尾段识别、正文替换、移除签名后的行为和转发边界；后端测试继续使用临时数据及本机模拟服务。

隔离原生验证覆盖首次空字段聚焦、中文姓名与邮箱关键词、无结果及空格隐藏、跨字段去重、键盘和鼠标补全、Esc 关闭及窗口失活。浮层出现前后，三个收件字段、主题与正文坐标一致。另完成 9 项剪贴板检查，核对 Finder 文件及剪贴板图片保存后的字节、普通文字粘贴、文件类型、目录和超限错误；Word 表格及图片、签名置底、长正文滚动和撤销均检查。详细证据见 [界面记录](UI_REVIEW.md#2026-10-22写信与附件预览修复)。
