# 0.0.15：独立配置导出与导入

发布日期：2026-10-22。App 与本机后端统一为 **0.0.15**，构建号 **16**，本地 Git 标签为 `v0.0.15`。本次将配置迁移功能纳入源码、日常开发 App 和 Release ZIP；包内 `版本信息.txt` 记录标签、完整源码提交号和生成时间。入口见 [文档索引](README.md)。

## 功能变化

- 在“设置 > 高级”新增独立配置卡片，导出已保存的邮箱参数与授权码、AI 配置与 API Key、自定义提示词、签名及其他偏好。按用户要求使用未加密 JSON，导出按需读取系统钥匙串，导入不读取旧凭证或增加应用内授权步骤。
- 选择文件后先显示账号新增、更新数量，以及 AI 地址和模型摘要。预览不显示密钥值，取消不应用；同邮箱忽略大小写后合并，保留原账号 ID，新增邮箱建立新账号，其他账号及已有邮件、附件和草稿保留。
- 配置与新凭证引用在同一数据库事务中提交，校验、冲突或提交失败保留原配置。提交成功后先采用新设置，再刷新邮件列表；刷新失败后继续点击“应用”仍保留导入的 AI、签名和偏好。
- 卡片、SF Symbols、系统字体、蓝灰色、无边框图标文字按钮及状态提示沿用现有设计，完整备份与恢复继续保留。

## 数据与兼容性

沿用 SQLite `user_version=2`。新增可选的 `settings.credentialReferences` 只保存钥匙串项引用，普通设置保存及重启均保留，密钥不写入 SQLite；导出文件移除本机引用及同步历史。现有账号、邮件、附件、草稿和待同步操作继续使用原数据。

配置文件支持格式版本 1、100 个账号及 2 MB 以内的 JSON。未包含邮件、附件、草稿、AI 结果、模型列表缓存和本机保存位置；这些数据继续通过完整备份迁移，完整备份不含钥匙串。JSON 包含授权码与 API Key，请妥善保管。具体范围和合并行为见 [配置迁移说明](CONFIGURATION_TRANSFER.md)。

原生验证使用独立 App、数据和钥匙串服务及合成凭证，完成导出、损坏文件错误、取消预览、1 个账号新增、1 个账号更新、其他账号与邮件草稿保留、签名与提示词应用、重启后再次导出并核对密钥。导入未读取旧凭证；故障注入确认提交后列表刷新失败，再次“应用”仍保留新签名、模型和凭证引用。界面复查的问题已修复并通过复核，详见 [界面记录](UI_REVIEW.md#2026-10-22配置导出与导入)。
