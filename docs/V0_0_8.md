# 0.0.8：精简总结、统一结果与界面优化

历史阶段记录。当前发布版本为 [0.0.13](V0_0_13.md)，本文保留本阶段的功能、产物与验收数字。

历史版本记录，对应本地标签 `v0.0.8`。当前版本与文档入口见 [文档索引](README.md)，下方测试数量和产物信息保留本版本验收时的状态。

本版本调整附件结果交互、Markdown 样式和默认总结风格，统一全局排版、控件反馈与动效，并修复账号长文本和摘要留白问题。本地标签 `v0.0.8` 一并收录 0.0.6、0.0.7 阶段的功能；各阶段的实现与验收记录分别保留。

## 结果整行展开

附件结果总入口和每个文件标题改为独立原生按钮。文字、箭头及右侧空白区域均可触发展开或收起；复制按钮放在同行的独立位置。标题不再启用文本选中，结果正文继续支持选择和复制。按钮保留键盘及辅助功能语义，读出已展开或已收起。

## Markdown 统一样式

邮件附件区和附件预览复用 `AnalysisDocumentView`，统一正文、标题、间距、颜色、表头、引用边线及代码字体。常见 Markdown 支持分级标题、有序和无序列表、嵌套列表、任务项、粗体和斜体、行内代码、表格、引用、围栏代码块、分隔线与链接。表格保留字段关系和对齐，较宽时可横向滚动；代码保留缩进和原始内容。

兼容原有“文件主题：”等标题及中文编号内容。中文冒号等标点紧接强调标记时，显示层补足原生解析器所需的分隔，避免漏出星号；行内代码不应用此处理。小数和日期不误识别为列表，表格中的转义竖线及行内代码不切断列。链接继续使用原有外部地址检查，Markdown 不执行 HTML 或脚本。本次没有增加脚注、数学公式或在线图片加载。

## 精简总结与下一步

总结卡只保留一个标题，正文分为三部分：

- 内容概要：一小段核心结论和必要背景，通常 100 至 220 字，保留影响决策的截止时间、金额、提交方式和限制，必要时可适当更长。
- 待处理：合并为 1 至 3 项必要事项，保留勾选和截止时间；没有明确待办时说明暂无待办。
- 您可继续：2 至 4 条短建议。有操作入口的建议用带箭头按钮，线下准备事项仅作为提醒。

起草回复建议衔接现有的待审核预览，用户使用内容后才创建草稿，发送继续确认。附件建议打开本封附件结果，有未理解项或中断任务时开始或继续批量理解，已成功结果复用。建议不会在生成总结时自动执行，后端只允许 `reply`、`attachments`、`note`，其他动作降为文字提醒。

总结增加 `overview` 与 `nextSteps`，兼容原有 `points`、`todos`、`keyInfo`。关键信息默认展开，仍可点击标题收起，复制包含完整概要、待办、建议和关键信息。默认提示词更新后，启动只迁移与旧默认文本相同的配置，自定义提示词及模型设置保留。已有总结不自动重写，重新生成时使用当前设置。

## 全局排版、账号与动效

统一系统字体层级、间距、蓝色强调、按钮点击范围与键盘焦点。次要操作移除描边，附件使用统一的 SF Symbols 并移除图标底框；邮件工具栏、草稿、整理、写信、搜索和七个设置页面同步调整。

账号切换弹层加宽至 360 pt，头像和选中标记保留宽度，名称与邮箱各占一行。超长内容居中省略，悬停可查看完整文字；侧栏入口与设置账号列表采用相同规则。

摘要总览和邮件内 AI 总结共用 `SummaryCard` 与 `SummaryContentLayout`，宽屏将概要、待办及后续操作、关键信息分为三列，中等宽度将关键信息放在概要下方，窄窗口纵向排列。布局按各列实际宽度测量高度，长待办、联系人和截止时间完整换行，不再使用固定的 320 pt 待办列。

保留并补充筛选与 AI 标签滑动选中、面板及结果展开、任务进度和数字过渡、勾选反馈、复制成功状态。系统启用“减少动态效果”时移除位移与弹动，保留短时颜色和状态反馈。具体布局断点、动效参数与检查记录见 [UI 调整说明](UI_REVIEW.md)。

## 验证记录

执行 `./script/test.sh`：87 项后端测试、24 项 Swift 测试通过。本次新增 5 项后端测试与 5 项 Swift 测试，覆盖新旧总结响应、动作范围、无效建议、提示词迁移、Markdown 表格、代码保留、中文强调、列表和日期。测试服务改为合并原始 HTTP 字节后解码，避免长中文提示词在分段处产生误报。

原生验收使用隔离数据和钥匙串服务名的测试副本、本机模拟 Responses 服务，验证：

- 整行展开和收起总结果、展开文件结果。
- 同一份 Markdown 在邮件内及预览中的标题、表格、列表、引用、代码及中文粗体显示一致。
- 精简摘要保留截止时间和限制，“您可继续”正常显示；点击起草建议生成预览，未增加草稿或发送邮件。
- 附件建议打开已有结果，不重复调用 AI；旧默认提示词在启动时升级。
- XLSX 原文件预览仍可显示格式及内嵌图片。

后续 UI 检查使用独立演示数据目录和预置结果，覆盖宽窗口摘要三列、邮件内两列、1150 pt 最小窗口单列，普通及超长账号、完整截止时间、关键信息展开收起、复制反馈、附件中心、草稿保存关闭和七个设置页面。App 编译、打包、启动、签名及 `git diff --check` 通过；Impeccable 布局静态扫描无报告。系统降低动态偏好的分支已实现，未切换系统偏好进行完整辅助功能验收。
