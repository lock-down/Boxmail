# Boxmail

<img src="Sources/BoxmailCore/Resources/BoxmailMark.png" alt="Boxmail" width="80" height="80">

Boxmail 是 macOS 邮件客户端。它用 IMAP 和 SMTP 收发邮件，在本机保存邮件与索引。要使用 AI 功能，可以接入自己的 API 密钥，支持 OpenAI Responses、Chat Completions 和 Anthropic Messages。

**Boxmail 1.0.0（构建号 52）**可从 GitHub 下载，安装包适用于 Apple Silicon。[下载 1.0.0](https://github.com/lock-down/Boxmail/releases/tag/v1.0.0) · [安装说明](docs/RELEASE_NOTES.md) · [更新日志](CHANGELOG.md)

## 功能

- 多账户收发、HTML 与内嵌图片阅读、可恢复的历史同步、引用链会话。
- 同一发件人聚合折叠，默认开启，组间及组内均按最新时间倒序，可切回逐封显示。展开后在缩进的子列表分页查看历史邮件。
- 最多两个账户并行同步，清单与下载分别显示进度，超时后保留断点；“设置 > 开发者”可导出脱敏诊断日志。
- 紧凑邮件列表、原生连续及离散多选、批量归档／删除／标记／编辑标签，以及最近一次手动操作的即时撤销；支持键盘切换邮件、搜索和批量处理。
- 富文本草稿、字号与颜色、粗体、列表与链接、联系人补全、回复与转发、个人签名、附件选择与粘贴，发送前确认；IMAP 草稿同步保留双方编辑冲突，正文按需加载，转发原文独立保存。
- 读信时一键翻译，可按邮箱开启外语邮件 Auto。目标语言按邮箱记忆，译文沿用原邮件排版。
- 「待办清单」按来源邮件显示摘要、待办和手工跟进，可按未读、全部或最近封数选信，预览后批量整理，也可按邮箱开启新邮件自动整理。
- 收件箱支持手工多标签和标签筛选。标签匹配条件可选信试用，确认后应用。
- 写信时从格式栏打开「帮我写」，可改写选区或正文，也可根据原邮件或已缓存会话生成回复候选。支持风格预设和输出语言，采用后可撤销。点击正文下方空白处可在正文末尾续写，点击签名文字可编辑签名。
- 草稿可更换发件账户，保存后移到所选账户的草稿箱。待发送邮件也在草稿箱，可继续编辑、改期或取消发送。
- 中文全文与组合条件搜索、本机草稿搜索、自定义标签，以及基于 pi-ai 1.3.0 的多服务商 BYOK、协议选择、模型能力及推理等级配置。
- 配置与密钥迁移、完整备份恢复、自定义数据目录及搜索索引重建；导入前展示邮箱主机与凭证处理方式，端点变化后提示重填凭证。

搜索可匹配附件名称和已提取内容。打开来源邮件即可预览、下载或转发附件。已有整封分析、会话结论、旧回复、问答及附件分析按来源只读查看。在待办清单打开「整理助手」，可使用现有标签、创建标签或起草规则。关闭整理窗口后，可在待办清单继续查看或停止批次。活动记录保留批次结果、规则执行记录及 AI 用量。

窄窗口从左上角打开邮箱导航抽屉。写信时按需展开「帮我写」、抄送和密送，底栏提供附件和发送操作。设置支持取消和保存，邮箱账户单独保存。操作见 [使用指南](docs/USER_GUIDE.md)。

## 开发运行

开发需要 macOS、Swift 6.0 或更高版本、Node.js 24.22.2 LTS 或更新的 LTS 版本及 npm。构建、测试和后端启动时会检查 Node.js 版本，App 内置构建时通过检查的运行时。在仓库根目录执行：

```bash
./script/build_and_run.sh
```

脚本安装缺失的后端依赖，编译并打包本机服务及运行时，关闭已运行的 Boxmail，再启动 `dist/Boxmail.app`。日常开发版默认不生成演示数据，隔离验收模式 `--review` 保留演示数据。Codex Run 使用同一入口；`swift run` 不会准备 App 所需的后端资源。

```bash
./script/test.sh
```

测试源码与样例仅保留在本地，`Tests/` 和 `Backend/test/` 不进入 Git；新检出需先准备这些目录才能运行回归。测试脚本先构建 PPT 原生渲染组件，再运行后端和 Swift 测试，缺少目录时会明确退出。联调、签名及发布步骤见 [开发说明](docs/DEVELOPMENT.md)。

## 安装包

从干净且已提交的工作区执行：

```bash
./script/package_app.sh
```

产物位于 `dist/`，文件名为 `Boxmail-v<版本>-macos-<架构>-clean.zip`，附 SHA-256 校验文件。包内包含 App、Node.js、生产依赖、使用说明、更新说明和版本信息。包内记录完整源码提交号，新安装关闭演示数据。

1.0.0 声明最低 macOS 14。Apple Silicon 安装包在 macOS 27.2.1 上验证，由 Swift 6.4.2 构建并内置 Node.js 26.13.1 LTS。发布包采用临时签名，首次配置与系统提示见 [使用指南](docs/USER_GUIDE.md)。

## 项目结构

```text
Sources/Boxmail/                      SwiftUI 界面、状态、本机凭证及后端生命周期
Sources/BoxmailCore/                  数据模型、共享资源及本机存储逻辑
Sources/BoxmailPresentationRenderer/  PPT 本机逐页渲染
Backend/src/                         HTTP、SQLite、邮件协议、AI 和附件处理
Backend/test/                        本地后端回归和合成样例，不跟踪
Tests/                               本地 Swift 回归，不跟踪；存在时自动启用测试目标
docs/                                使用指南、UI 规范、开发说明及路线
script/                              构建、启动、测试、打包和图标生成
```

默认数据目录为 `~/Library/Application Support/Boxmail/`。邮箱授权码和 API Key 保存在该目录的 `.env` 文件，设置界面自动读写，同步、发信和 AI 调用无需钥匙串授权。文件以明文保存，App 写入时权限为 `0600`，可从“设置 > 高级 > 本机数据 > 查看凭证”定位。服务器地址、模型及偏好继续由设置界面保存。

如需使用仓库内的配置文件，可参考 [.env.example](.env.example)：

```bash
cp .env.example .env
BOXMAIL_ENV_FILE="$PWD/.env" ./script/build_and_run.sh
```

`BOXMAIL_ENV_FILE` 必须是绝对路径，省略时使用当前数据目录下的 `.env`。旧钥匙串凭证不会自动读取；升级后重新填写并保存授权码、API Key，或导入此前导出的配置 JSON。完整 ZIP 备份不包含 `.env`；默认位置的文件随数据目录迁移，外部指定文件保留在原位置。调用云端 AI 会将任务所需邮件或附件内容提交给所配置的服务商。本机邮件缓存、凭证文件、完整备份和配置导出均未加密，具体范围见使用指南。
